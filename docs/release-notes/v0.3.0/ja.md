## 新機能

- エージェント管理に WorkBuddy / WorkBuddy AI 連携を追加しました。インストール検出、設定の適用と解除、バックアップと復元、起動と再起動に対応します。オブジェクト形式と配列形式の `models.json` を扱い、既存のカスタムモデルは保持します。適用後は WorkBuddy で `CPA:モデル名` を選択してください。既存の会話のモデルは自動では切り替わりません。表示されない場合は App を再起動してください。
- エージェント管理に Cursor CLI（`cursor-agent`）連携を追加しました。ローカルインストールを検出し、任意のターミナルと作業ディレクトリから起動できます。Cursor CLI は CPA のローカルモデルルーティングではなく、独自の設定とアカウントを使用します。
- エージェント管理に Antigravity CLI 連携を追加しました。CPA の Gemini 互換 API 経由で接続します。設定適用後はこのページから起動し、そのプロセスに接続先と API キーを渡してください。`agy` を直接実行する場合は、環境変数を自分で設定する必要があります。

## 改善

- ホームの API 接続カードを横並びの行表示に変更し、プロトコルごとに 1 行、操作パネルと同じ高さに揃えました。URL をクリックするとローカルまたは LAN アドレスをコピーでき、コピー結果も分かりやすく表示します。
- 使用記録の概要を 6 枚の統計カードを 1 行に収めるレイアウトに整理し、内容をコンパクトにして行幅を揃えました。リクエスト数、パフォーマンス、トークン、費用を素早く確認できます。
- 同梱コアを 7.3.10 に更新しました。

## 修正

- 使用記録のトレンドグラフで、マウスを乗せた直後にデータツールチップが消える問題を修正しました。ポインターがグラフ上にある間は表示を維持し、グラフから外すか Esc を押したときだけ閉じます。

## v0.2.101 の更新内容

### 修正

- API 接続で、選択していない上流モデルの名前が選択済みモデルのエイリアスと一致すると、自動生成された除外ルールによって選択済みモデルまで利用できなくなる問題を修正しました。例えば、上流モデル `dsv4.1` のエイリアスを `dsv4` に設定した場合、元の `dsv4` を選択していなくても、このマッピングを利用できます。
- モデルの選択を適用した後にモデル名やエイリアスを編集すると、自動生成された除外ルールも更新されるようにしました。保存時には、同じモデルに設定済みの別のエイリアスも保護します。手動で編集した除外リスト、ワイルドカードのルール、プロバイダーの無効状態は保持されます。

**既存の設定について：** 競合する除外ルールがすでに保存されている場合は、「モデルを取得 → 選択を適用 → 保存」を再度行うと、自動生成された競合ルールを解消できます。
