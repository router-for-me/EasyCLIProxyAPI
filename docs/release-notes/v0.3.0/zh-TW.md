## 新增

- 智慧代理管理新增 WorkBuddy / WorkBuddy AI 接入。可偵測安裝、套用或關閉設定、備份與還原，以及啟動或重新啟動用戶端。支援物件與陣列兩種 `models.json` 格式，並保留既有自訂模型。套用後請在 WorkBuddy 中選擇 `CPA:模型名`；既有工作階段不會自動切換，未顯示時可重新啟動 App。
- 智慧代理管理新增 Cursor CLI（`cursor-agent`）接入。可偵測本機安裝，並依自訂終端機與工作目錄啟動。Cursor CLI 使用自身設定與帳號體系，不走 CPA 本機模型路由。
- 智慧代理管理新增 Antigravity CLI 接入。透過 CPA 的 Gemini 相容介面連線；套用設定後請從本頁啟動，以便為該行程注入介面位址與金鑰。直接執行 `agy` 時需自行設定環境變數。

## 優化

- 首頁 API 接入改為橫向卡片，每種協定單獨一行，並與控制區保持等高。可直接點擊 URL 複製本機或區域網路位址，複製後會顯示明確回饋。
- 使用記錄總覽改為單列顯示 6 張統計卡片，收合卡片內容並統一列寬，方便快速查看請求量、效能、Token 與費用。
- 內建核心更新至 7.3.10。

## 修正

- 修正使用記錄趨勢圖的資料提示框在滑鼠停留時短暫出現後消失的問題。現在只要指標仍在圖表上，提示框就會持續顯示；移出圖表或按下 Esc 後才會關閉。

## v0.2.101 更新內容

### 修正

- 修正 API 接入中，未勾選的上游模型名稱與已選模型的別名相同時，自動產生的排除規則誤擋已選模型的問題。例如，將上游 `dsv4.1` 的別名設為 `dsv4` 後，不會再因未勾選原本的 `dsv4` 而導致該對應無法使用。
- 套用模型選擇後，編輯模型名稱或別名會同步更新自動排除規則；儲存時也會保護同一模型已有的其他別名。手動編輯的排除清單、萬用字元規則及供應商停用狀態會繼續保留。

**現有設定：** 若先前已儲存衝突的排除規則，請重新取得模型、套用選擇並儲存，以清除自動產生的衝突規則。
