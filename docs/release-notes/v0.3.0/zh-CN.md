## 新增

- 智能体管理新增 WorkBuddy / WorkBuddy AI 接入。可检测安装、应用或关闭配置、备份与恢复，以及启动或重启客户端。支持对象和数组两种 `models.json` 格式，并保留已有自定义模型。应用后请在 WorkBuddy 中选择 `CPA:模型名`；已有会话不会自动切换，未显示时可重启 App。
- 智能体管理新增 Cursor CLI（`cursor-agent`）接入。可检测本地安装，并按自定义终端与工作目录启动。Cursor CLI 使用自身配置与账号体系，不走 CPA 本地模型路由。
- 智能体管理新增 Antigravity CLI 接入。通过 CPA 的 Gemini 兼容接口连接；应用配置后请从本页启动，以便为该进程注入接口地址和密钥。直接运行 `agy` 时需自行设置环境变量。

## 优化

- 首页 API 接入改为横向卡片，每种协议单独一行，并与控制区保持等高。可直接点击 URL 复制本机或局域网地址，复制后会给出明确反馈。
- 使用记录总览改为单行展示 6 张统计卡片，收紧卡片内容并统一行宽，便于快速查看请求量、性能、Token 和费用。
- 内置内核更新至 7.3.10。

## 修复

- 修复使用记录趋势图的数据提示框在鼠标停留时短暂出现后消失的问题。现在只要指针仍在图表上，提示框就会保持显示；移出图表或按 Esc 后才会关闭。

## v0.2.101 更新内容

### 修复

- 修复 API 接入中，未勾选的上游模型名与已选模型的别名相同时，自动生成的排除规则误伤已选模型的问题。例如，将上游 `dsv4.1` 的别名设为 `dsv4` 后，不会再因未勾选原来的 `dsv4` 而导致该映射不可用。
- 应用模型选择后，编辑模型名称或别名会同步更新自动排除规则；保存时也会保护同一模型已有的其他别名。手动编辑的排除列表、通配符规则及提供商停用状态会继续保留。

**已有配置：** 如果此前已保存了冲突的排除规则，请重新执行“获取模型 → 应用选择 → 保存”，清理自动生成的冲突规则。
