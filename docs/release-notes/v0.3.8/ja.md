## 追加

- Linux にシステムトレイを追加しました。トレイからメイン画面を開く、コアの状態を確認する、コアを起動・停止・再起動する、アプリを終了する操作ができます。ウィンドウを閉じた後のトレイ常駐とサイレント起動にも対応しました。

## 改善

- 同梱コアを 8.0.2 に更新しました。API プロバイダー、アクセスキー、OAuth モデルエイリアス、リクエスト設定などの読み書きについて、コア v8 の設定形式と管理 API に対応しました。
- 狭いウィンドウでのレイアウトを改善しました。言語メニュー、ページのタブ、ダイアログ、使用履歴にキーボード操作、フォーカス管理、アクセシビリティ用のラベルを追加しました。使用履歴の列幅もキーボードで調整できます。
- 対応していないシステム言語では英語を既定にしました。従来中国語で固定されていたバックエンドのメッセージを英語に統一し、トレイメニューはアプリの言語に合わせて表示します。

## 修正

- コア v8 の任意の設定項目が存在しない場合に画面の読み込みが失敗する問題を修正しました。モデルエイリアスの初回作成と保存失敗後のロールバックを改善し、空の親設定項目を別の変更と誤認しないようにしました。
- CPA ゲートウェイ経由で Claude Code を使う際に、サーバー側の自動モードチェックが実行される場合がある問題を修正しました。
- macOS で、旧バージョンの相対パス指定の OAuth 認証情報ディレクトリが原因で、アップグレード後に既存の認証情報を読み込めない問題を修正しました。相対パス側に認証情報がなく、永続保存先にある場合は、既存の保存先を自動的に使用します。
- Linux でシステムトレイを利用できない場合はメインウィンドウを表示し、サイレント起動や最小化後にアプリを再表示できなくなる問題を防ぎます。
- 旧バージョンの相対パス指定の OAuth 認証情報ディレクトリを自動復旧する処理を Windows と Linux にも拡張し、macOS のパス判定を改善しました。復旧に失敗した場合も既存の設定と認証情報を保持します。
- 各 OS で OAuth 認証情報とコアログのディレクトリを正しく解決し、開いたディレクトリと起動ログの保存先がコアの使用するパスと一致するようにしました。
- バージョン情報がなくても v8 形式を使用している設定で、TLS、ログ、OAuth 認証情報ディレクトリなどの設定が誤った場所に書き込まれる問題を修正しました。フロー形式の YAML マッピングの更新にも対応しました。
