## 新增

- **标签筛选改为单行 + 悬浮多选面板**：ECPA 精选页和插件商店页的标签筛选默认只占一行，超出的标签收进行尾的下拉箭头里。点开后在卡片上方浮出选择面板，可同时勾选多个标签（勾选结果取并集），面板不会把下方的插件列表往下推。面板在空间不足时会向上展开，标签较多时在面板内滚动，最后一行的选项不会被截断。

## 优化

- **精选插件首屏一次成形**：精选页会等注册表和插件源列表都返回后才渲染卡片网格，加载期间只显示一个居中的加载占位，不会再出现「先画卡片骨架、数据回来后再补内容」的跳动。
- **卡片高度不再随加载态变化**：卡片里的安装按钮使用固定宽度槽位，文案在「安装 / 安装中 / 更新」之间切换时不会撑开卡片，也不再插入「正在加载插件列表…」的提示条。
- **插件商店页面与精选页对齐**：商店卡片改成和精选页相同的结构（图标、名称与 ID、右上角版本徽标、描述、作者与协议、标签、底部分隔线加操作条），操作条同样是「复制插件 ID / 打开链接 / 右侧主按钮」。商店工具栏收敛为「搜索 + 开发指南 + 刷新」一行，仅比精选页多出开发指南；原先夹在中间、会换行的下拉选择器、检查更新和本地安装按钮已移出工具栏。
- **插件停用提示改为工具栏小胶囊**：插件全局停用时不再插入一整条横幅打断页面结构，改为工具栏里的短提示，完整说明放在悬停提示里。

## 修复

- **反向代理设置重启后丢失**：反向代理设置此前只写在会随内核启动重新生成的内核配置里，重启后可能被覆盖。现在改为保存在 GUI 配置文件中，并在保存时同步内存状态，避免一次无关的配置保存把它序列化掉。
- **反向代理设置在内核配置与 GUI 配置之间迁移时丢失**：从内核配置迁移到 GUI 配置的过程改为在同一步内同时更新文件与内存状态，只有两处写入都成功后才从内核配置中移除，写入失败时保留原值并在下次启动重试。
- **反向代理启动错误残留**：启动成功后清除之前的绑定或恢复错误，避免界面一边显示「运行中」一边挂着旧报错。
