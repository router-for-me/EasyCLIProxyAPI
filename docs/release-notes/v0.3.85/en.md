## Improved

- **Codex model catalog reload and sort reset now live in the footer**: both actions used to sit inside the left model list, so a long list meant scrolling to reach them. They are now pinned to the left side of the bottom toolbar, on the same row as save and restore, and always within reach.
- **Sort reset stays disabled when there is nothing to reset**: until the catalog loads or a custom order exists, the reset button remains disabled so the order cannot be cleared by accident.
- **Hints and actions are separated**: unsaved and saved messages render in their own right-aligned area while the action buttons stay anchored to the bottom right, so the footer no longer collapses in narrow windows.
