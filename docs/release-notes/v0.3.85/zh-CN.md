## 优化

- **Codex 模型目录的重载与排序重置移到页脚**：这两个操作原先挤在左侧模型列表里，列表一长就得滚动才能点到。现在它们固定在底部工具栏左侧，与保存、恢复等操作同一行，随时可用。
- **排序重置在无改动时不再可用**：目录还没加载或没有自定义排序时，重置按钮保持禁用，不会误触清空顺序。
- **提示信息与操作按钮分区显示**：未保存、已保存等提示居中偏右显示，操作按钮固定在右下角，页脚在窄窗口下不再被文字挤乱。
