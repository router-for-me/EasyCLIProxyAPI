## 改善

- **Codex CLI の検出と起動**：各検出・起動処理で検証済みの実行パスとバージョンを再利用し、重複したバージョン確認を減らして、検出した CLI と同じプログラムを起動します。

## 修正

- **Codex CLI の選択順序**：手動指定パス、`CODEX_CLI_PATH`、PATH、従来の CLI インストール先の順に検索します。デスクトップ版専用の CLI ディレクトリを自動検索して、コマンドライン版より優先する動作を取り除きました。
- **無効なパスと遅いランチャー**：明示した CLI が使えない場合は、別のインストールへ黙って切り替えずエラーを表示します。Unix ではバージョン確認の子プロセスを終了し、出力パイプの保持によるタイムアウト後の待機を防ぎます。
