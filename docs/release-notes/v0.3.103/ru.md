## Улучшено

- **Обнаружение и запуск Codex CLI**: Проверенные путь и версия повторно используются внутри каждой операции обнаружения или запуска. Это устраняет повторные проверки версии и сохраняет выбранный исполняемый файл при запуске.

## Исправлено

- **Выбор Codex CLI**: Сначала используется путь, выбранный вручную, затем `CODEX_CLI_PATH`, PATH и прежние резервные каталоги установки CLI. Закрытые каталоги настольного приложения больше не сканируются автоматически и не получают приоритет над установленной командной строкой.
- **Неверные пути и медленные оболочки запуска**: Если явно заданный CLI недоступен, показывается ошибка вместо незаметного выбора другой установки. В Unix дочерние процессы проверки версии завершаются, чтобы удерживаемые ими каналы вывода не продлевали ожидание после тайм-аута.
