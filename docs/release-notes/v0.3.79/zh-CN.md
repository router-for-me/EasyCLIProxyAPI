这个版本给路由编排加了一个"隐藏已禁用"的开关，凭证多的时候一眼能看清真正在干活的层级；顺手修掉了使用记录表格顶部那条多余的横向滚动条，并让 GitHub Actions 不再为每个外部 PR 都跑一遍完整打包。

如果你在使用中遇到问题，请通过 [QQ群](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 反馈，我们会尽快处理。

## 新功能

- **路由层级视图可以临时隐藏已禁用凭证**：路由编排页面右上角新增「隐藏已禁用」按钮。开启后，已禁用的凭证不再出现在层级卡片里，整层都被禁用时该层级也会一起收起来，层级编号仍然连续，拖动和拆分操作照常可用。这个开关只影响你看到的画面，不会改动能耗配置、优先级或路由方案；选择会被记住，下次打开还是上次的状态。

## 修复

- **使用记录的横向滚动条出现两条**：请求明细表格顶部和底部的滚动条会重复叠加。现在顶部那条滚动条用可自适应的轨道宽度跟随表格内容，内容不需要横向滚动时它会自动消失，不再和底部原生滚动条抢位置。

## 优化

- **PR 构建不再人人有份**：GitHub Actions 的打包工作流现在只对仓库维护者提交的 PR 触发，外部贡献的 PR 不再自动跑完整的多平台构建，省下队列时间给正式发布。
