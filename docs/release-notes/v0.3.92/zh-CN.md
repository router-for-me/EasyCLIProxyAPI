## 优化

- **插件设置页**：删除商店来源和认证规则输入框下方的两行冗余提示。说明「ECPA 精选目录会自动注册为插件源」的那一行保留，因为它标示的是软件自动为你添加的来源。

## 修复

- **精选插件列表停留在旧快照**：ECPA 精选页不再回退到随安装包打包的注册表副本。读取失败时改为显示空列表并给出明确错误，而不是静默展示打包时冻结的插件。
- **注册表切换到 schema 第 2 版后精选插件消失**：解析器此前只接受 `schema_version` 1，导致下载成功的内容被直接丢弃，页面显示为读取失败。现在两代 schema 都接受，未知版本仍然拒绝。
- **刷新成功后仍残留失败提示**：点击刷新会清除之前的「ECPA 插件源读取失败」提示；刷新失败时也会清空旧列表，页面不会再出现「有插件卡片却挂着失败提示」的矛盾状态。
- **网络设置中 SOCKS 代理地址被拒**：`socks://`、`socks5://` 和 `socks5h://` 不再区分大小写，`socks://` 会自动规范化为 `socks5://`。
