## 最佳化

- **外掛設定頁**：移除商店來源與認證規則輸入框下方的兩行冗餘提示。說明「ECPA 精選目錄會自動註冊為外掛來源」的那一行保留，因為它標示的是軟體自動為你新增的來源。

## 修正

- **精選外掛清單停留在舊快照**：ECPA 精選頁不再回退到隨安裝包打包的註冊表副本。讀取失敗時改為顯示空清單並給出明確錯誤，而不是靜默顯示打包時凍結的外掛。
- **註冊表切換到 schema 第 2 版後精選外掛消失**：解析器先前只接受 `schema_version` 1，導致下載成功的內容被直接丟棄，頁面顯示為讀取失敗。現在兩代 schema 都接受，未知版本仍然拒絕。
- **重新整理成功後仍殘留失敗提示**：點擊重新整理會清除先前的「ECPA 外掛來源讀取失敗」提示；重新整理失敗時也會清空舊清單，頁面不會再出現「有外掛卡片卻掛著失敗提示」的矛盾狀態。
- **網路設定中 SOCKS 代理位址被拒**：`socks://`、`socks5://` 與 `socks5h://` 不再區分大小寫，`socks://` 會自動規範化為 `socks5://`。
