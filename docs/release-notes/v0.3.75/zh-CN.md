## 修复

- **预览版检测误报"暂无预览版"**：之前查询最新预览版时只走 GitHub 的接口，一旦匿名请求被限流（每小时 60 次）就会判定成"没有可用预览版"，而实际上预览版是存在的。现在会自动改用 GitHub 的订阅源重试，只有两个来源都失败才提示错误。
- **更新检测使用已配置的 GitHub 令牌**：设置里的 GitHub 访问令牌原本只给插件商店使用，版本更新检测仍发匿名请求。现在两者共用同一个令牌，配额从每小时 60 次提升到 6000 次，未配置时仍回退到匿名请求与订阅源。
- **检测失败后一直显示"检测中"**：应用更新检测出错时，「最新版本」一栏原本会永远停在"检测中"，与右上角的"检测失败"自相矛盾。现在会正确显示"检测失败"。
- **Agent 用量页签切回后丢失状态**：从其他页面回到「Agent 用量」时，顶部状态栏会错误地显示「等待内核」，实际本地采集仍在进行。现在会重新读取采集状态，正常显示「本地采集中」。

## 新增

- **用量统计自定义时间范围**：原本固定的「最近 24 小时」改为「自定义」，点击后展开快捷选项（昨天、本周、上周、本月、上月、最近 90 天、今年、去年）并可自行选择起止日期，统计会与前一等长周期对比。
- **活动日历自动适配宽度**：日历不再固定画满整年，而是按可用空间铺满并截止到今天，历史较长时才会横向滚动；小时热力图在空间允许时保持在同一行。
- **跨年标签显示年份**：日历的 1 月标签与趋势图坐标轴在跨年时会带出年份。
- **切换时间范围时保留统计粒度**：从小时切到天或月时，原本选中的粒度会保留；只有小时数据不可用时（选择「全部」或早于 30 天的自定义范围）才回退到按天。

## 优化

- **发版不再因上游查询失败而中断**：构建时会查询上游内核最新版本，此前三个来源全部失败就会直接中断该平台构建。现在会保留项目里已固定的内核版本继续构建，只有主动检查更新时才严格报错。
- **推送主分支不再触发完整构建**：每次推送 `main` 原本都会完整编译六个平台只为预热缓存，白白占用构建资源。现在只在打标签发版时构建，同时保证缓存照常写入，后续编译仍然命中缓存。
