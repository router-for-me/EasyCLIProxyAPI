## 修復

- **預覽版偵測誤報「暫無預覽版」**：先前查詢最新預覽版時只走 GitHub 的介面，一旦匿名請求被限流（每小時 60 次）就會判定成「沒有可用預覽版」，而實際上預覽版是存在的。現在會自動改用 GitHub 的訂閱來源重試，只有兩個來源都失敗才提示錯誤。
- **更新偵測使用已設定的 GitHub 權杖**：設定裡的 GitHub 存取權杖原本只給外掛商店使用，版本更新偵測仍發匿名請求。現在兩者共用同一個權杖，配額從每小時 60 次提升到 6000 次，未設定時仍回退到匿名請求與訂閱來源。
- **偵測失敗後一直顯示「偵測中」**：應用程式更新偵測出錯時，「最新版本」欄位原本會永遠停在「偵測中」，與右上角的「偵測失敗」自相矛盾。現在會正確顯示「偵測失敗」。
- **Agent 用量頁籤切回後遺失狀態**：從其他頁面回到「Agent 用量」時，頂部狀態列會錯誤地顯示「等待核心」，實際上本機擷取仍在進行。現在會重新讀取擷取狀態，正常顯示「本機擷取中」。

## 新增

- **用量統計自訂時間範圍**：原本固定的「最近 24 小時」改為「自訂」，點擊後展開快速選項（昨天、本週、上週、本月、上月、最近 90 天、今年、去年）並可自行選擇起訖日期，統計會與前一個等長週期比較。
- **活動日曆自動配合寬度**：日曆不再固定畫滿整年，而是依可用空間鋪滿並截至今天，歷史較長時才會橫向捲動；小時熱力圖在空間允許時保持在同一列。
- **跨年標籤顯示年份**：日曆的 1 月標籤與趨勢圖座標軸在跨年時會帶出年份。
- **切換時間範圍時保留統計粒度**：從小時切到天或月時，原本選取的粒度會保留；只有小時資料不可用時（選擇「全部」或早於 30 天的自訂範圍）才回退到按天。

## 優化

- **發版不再因上游查詢失敗而中斷**：建置時會查詢上游核心最新版本，先前三個來源全部失敗就會直接中斷該平台建置。現在會保留專案裡已固定的核心版本繼續建置，只有主動檢查更新時才嚴格報錯。
- **推送主分支不再觸發完整建置**：每次推送 `main` 原本都會完整編譯六個平台只為預熱快取，白白佔用建置資源。現在只在打標籤發版時建置，同時保證快取照常寫入，後續編譯仍然命中快取。
