## 修正

- **プレビュー版が「利用可能なプレビューがありません」と誤って表示される**：最新のプレビュー版を調べる際に GitHub の API しか使っていなかったため、匿名リクエストがレート制限（1 時間 60 回）に達すると、実際には存在するのに「プレビュー版がない」と判定していました。現在は GitHub のフィードで再試行し、両方の取得元が失敗した場合のみエラーを表示します。
- **更新チェックが設定済みの GitHub トークンを使うようになりました**：設定の GitHub アクセストークンはプラグインストアだけで使われ、バージョン更新チェックは匿名リクエストのままでした。現在は両方が同じトークンを共有し、上限が 1 時間 60 回から 6000 回に増えます。未設定の場合は従来どおり匿名リクエストとフィードを使用します。
- **チェック失敗後も「検出中」のままになる**：アプリの更新チェックが失敗しても「最新バージョン」欄が永久に「検出中」のままで、右上の「チェック失敗」と矛盾していました。現在は失敗状態を表示します。
- **Agent 使用量タブに戻ると状態が失われる**：他のページから「Agent 使用量」に戻ると、ローカル収集が続いているのに上部の状態バーが「コアを待機中」と表示していました。現在は収集状態を読み直し、「ローカルで収集中」と正しく表示します。

## 追加

- **使用量統計のカスタム期間**：固定の「過去 24 時間」を「カスタム」に置き換えました。クリックするとクイック選択（昨日、今週、先週、今月、先月、過去 90 日、今年、昨年）と開始・終了日が開き、同じ長さの直前の期間と比較します。
- **アクティビティカレンダーが幅に合わせて伸縮**：常に 1 年分を描くのをやめ、利用可能な幅いっぱいに今日までを表示します。履歴が長い場合のみ横スクロールし、時間別ヒートマップは収まる場合は同じ行に保たれます。
- **年をまたぐラベルに年を表示**：カレンダーの 1 月ラベルとトレンド軸のラベルに年を含めます。
- **期間を切り替えても粒度を保持**：時間別から日・週・月へ切り替えても選択した粒度を保持し、時間別データが使えない場合（「すべて」、または 30 日より古いカスタム期間）のみ日単位に戻ります。

## 改善

- **上流の照会失敗でリリースが中断しなくなる**：ビルド時に上流カーネルの最新版を照会し、以前は 3 つの取得元すべてが失敗するとそのプラットフォームのビルドを中断していました。現在は固定済みのカーネルバージョンを保ってビルドを続行し、明示的な更新チェックのみ厳格にエラーを返します。
- **main へのプッシュでフルビルドが走らなくなる**：以前は `main` へのプッシュごとにキャッシュを温めるためだけに 6 プラットフォームをビルドし、ランナーを無駄に使っていました。現在はリリースタグでのみビルドし、キャッシュは従来どおり書き込まれるため以降のビルドはキャッシュを利用できます。
