## Improved

- **Plugin OAuth cards show saved accounts**: each plugin card now lists the accounts already authorised for it, grouped by the credential provider it stored, with a preview of the first few and a count that opens the matching credential files. The login button reads “Add Account” once an account exists.

## Fixed

- **Browser choice for plugin login**: the auto-open picker in the top-right now applies to plugin providers as well. The selection is forwarded to the core, “do not auto-open” is honoured, and a plugin page that already opened is no longer opened a second time.
