## 改进

- **插件 OAuth 卡片显示已保存账号**：每个插件卡片现在会列出该插件已授权的账号，按凭证记录的 provider 分组，最多预览前几个并显示总数，点击总数可直接跳转到对应的凭证文件。已有账号时登录按钮显示为“添加账号”。

## 修复

- **插件登录的浏览器选择**：右上角的自动打开浏览器选项现在对插件 provider 同样生效。所选浏览器会传递给核心，选择“不自动打开”时不再自动打开，插件自身已打开的页面也不会被重复打开一次。
