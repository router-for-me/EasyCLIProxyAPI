## Улучшения

- **Карточки OAuth плагинов показывают сохранённые аккаунты**: каждая карточка плагина теперь перечисляет уже авторизованные для него аккаунты, сгруппированные по провайдеру из учётных данных, с предпросмотром первых нескольких и счётчиком, открывающим соответствующие файлы учётных данных. Если аккаунт уже есть, кнопка входа называется «Добавить аккаунт».

## Исправления

- **Выбор браузера при входе через плагин**: настройка автоматического открытия браузера в правом верхнем углу теперь действует и для провайдеров плагинов. Выбранный браузер передаётся ядру, режим «не открывать автоматически» соблюдается, а страница, которую плагин уже открыл, больше не открывается повторно.
