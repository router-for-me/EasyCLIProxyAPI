## 改善

- **プラグイン OAuth カードに保存済みアカウントを表示**: 各プラグインカードに、そのプラグインで認証済みのアカウントが表示されるようになりました。認証情報に記録された provider ごとにまとめ、先頭のいくつかをプレビューし、件数をクリックすると対応する認証ファイルを開きます。アカウントが既にある場合、ログインボタンは「アカウントを追加」と表示されます。

## 修正

- **プラグインログインのブラウザ選択**: 右上の自動起動ブラウザの設定がプラグインの provider にも適用されるようになりました。選択したブラウザはコアに渡され、「自動で開かない」を選ぶと自動起動せず、プラグインが既に開いたページを二重に開くこともなくなりました。
