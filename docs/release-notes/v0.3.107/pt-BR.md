## Melhorias

- **Cartões de OAuth de plugins mostram contas salvas**: cada cartão de plugin agora lista as contas já autorizadas para ele, agrupadas pelo provedor de credenciais armazenado, com prévia das primeiras contas e um contador que abre os arquivos de credenciais correspondentes. O botão de login passa a exibir “Adicionar conta” quando já existe uma conta.

## Correções

- **Escolha de navegador para login por plugin**: o seletor de abertura automática no canto superior direito agora também se aplica a provedores de plugins. A escolha é encaminhada ao núcleo, a opção “Não abrir automaticamente” é respeitada e uma página de plugin já aberta não é aberta uma segunda vez.
