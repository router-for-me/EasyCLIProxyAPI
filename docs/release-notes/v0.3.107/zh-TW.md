## 改進

- **外掛 OAuth 卡片顯示已儲存帳號**：每個外掛卡片現在會列出該外掛已授權的帳號，依憑證記錄的 provider 分組，最多預覽前幾個並顯示總數，點擊總數可直接跳轉到對應的憑證檔案。已有帳號時登入按鈕顯示為「新增帳號」。

## 修正

- **外掛登入的瀏覽器選擇**：右上角的自動開啟瀏覽器選項現在對外掛 provider 同樣生效。所選瀏覽器會傳遞給核心，選擇「不自動開啟」時不再自動開啟，外掛自身已開啟的頁面也不會被重複開啟一次。
