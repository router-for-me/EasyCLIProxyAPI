## Улучшения

- **Пустые записи удаляются автоматически**: Правила без исходного текста удаляются при сохранении, переключении страницы или уходе из строки, поэтому пустая заготовка больше не попадает в конфигурацию ядра и не учитывается в количестве правил.

## Исправления

- **Расположение кнопки отмены**: Кнопка отмены после удаления теперь находится в заголовке страницы вместо строки состояния, восстанавливает только правила с исходным текстом и не оставляет устаревшее сообщение.
- **Отображение ошибок**: Ошибки загрузки и сохранения открываются в диалоге, не сдвигая содержимое страницы, а пустая страница после загрузки больше не показывает нерабочую кнопку повтора.
