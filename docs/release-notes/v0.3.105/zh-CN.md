## 改进

- **自动丢弃空条目**：保存、切换页面或离开输入行时，没有原文的规则会被移除，空白占位不会再写入核心配置，也不会被计入规则数量。

## 修复

- **撤销入口位置**：删除后的撤销按钮移到页面标题栏，替换原来的状态提示条，只恢复仍有原文的规则，并且不会残留旧提示。
- **错误提示方式**：加载或保存失败改为弹窗显示，页面内容不再被提示条挤压；加载完成后空页面不再显示无效的重试按钮。
