## 修正

- **額度卡片不再繪製空的重置次數框**：當帳號既沒有額度餘額也沒有可用的重置次數時，卡片底部不再出現空白方框；重置次數查詢失敗時，提示改為顯示在卡片下方，不再被塞進框內。
- **額度卡片配色跟隨主題**：重置次數區塊改用主題的柔和底色，淺色主題下不再顯示成突兀的深色。
- **額度限額名稱統一**：各供應商的限額名稱統一改用「限額」表述（例如「5 小時限額」「週限額」「Opus 週限額」），不再混用「視窗」與「額度」兩種說法；英文、簡體中文、繁體中文與日文同步調整。
- **用量頁兩個面板不再撐滿視窗**：「價格統計」與「資料管理」面板現在跟隨內容高度結束，不再向下撐滿整個視窗；價格清單較長時仍會在面板內捲動。
- **窄視窗下頂部導覽自動露出目前頁面**：當視窗較窄、導覽變成頂部橫向排列時，從其他頁面按鈕開啟的頁面會把對應的導覽項目自動捲動到可見位置；寬視窗的側邊欄維持不變。
