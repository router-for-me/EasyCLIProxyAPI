## 修正

- **クォータカードに空のリセット回数欄を表示しない**: クレジット残高も利用可能なリセット回数もない場合、カード下部に空の枠が出なくなりました。リセット回数の取得に失敗したときは、枠の中ではなくカードの下に通知を表示します。
- **クォータカードの配色がテーマに追従**: リセット回数欄がテーマの柔らかい背景色を使うようになり、明るいテーマで不自然な暗いブロックとして見えなくなりました。
- **クォータ上限の名称を統一**: 各プロバイダーの上限名を「5 時間制限」「週間制限」「Opus 週間制限」のように統一し、「ウィンドウ」と「クォータ」の混在を解消しました。英語・簡体字中国語・繁体字中国語・日本語を同時に更新しています。
- **使用状況ページのパネルがウィンドウ全体を埋めない**: 「価格統計」と「データ管理」のパネルが内容の高さで終わるようになり、ウィンドウ下端まで引き伸ばされなくなりました。価格リストが長い場合はパネル内でスクロールします。
- **狭いウィンドウで現在のページが上部ナビゲーションに表示される**: ウィンドウが狭くナビゲーションが上部の横一列になるとき、別ページのボタンから開いたページのナビゲーション項目が自動的に見える位置までスクロールされます。広いウィンドウのサイドレールはそのままです。
