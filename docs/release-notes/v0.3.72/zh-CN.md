## 修复

- **额度卡片不再画空的重置次数框**：当账号既没有额度余额也没有可用的重置次数时，卡片底部不再出现一个空白的框；重置次数查询失败时，提示改为显示在卡片下方，不再被塞进框里。
- **额度卡片配色跟随主题**：重置次数区域改用主题的柔和底色，浅色主题下不再显示成一块突兀的深色。
- **额度限额名称统一**：各供应商的限额名称统一改用「限额」表述（如「5 小时限额」「周限额」「Opus 周限额」），不再混用「窗口」与「额度」两种说法；英文、简体中文、繁体中文与日文同步调整。
- **用量页两个面板不再被拉满窗口**：「价格统计」与「数据管理」面板现在跟随内容高度结束，不再向下撑满整个窗口；价格列表较长时仍会在面板内滚动。
- **窄窗口下顶部导航自动露出当前页**：当窗口较窄、导航变成顶部横向排列时，从其他页面按钮打开的页面会把对应的导航项自动滚动到可见位置；宽窗口的侧边栏保持不动。
