## 修正

- 修正 API 接入中，未勾選的上游模型名稱與已選模型的別名相同時，自動產生的排除規則誤擋已選模型的問題。例如，將上游 `dsv4.1` 的別名設為 `dsv4` 後，不會再因未勾選原本的 `dsv4` 而導致該對應無法使用。
- 套用模型選擇後，編輯模型名稱或別名會同步更新自動排除規則；儲存時也會保護同一模型已有的其他別名。手動編輯的排除清單、萬用字元規則及提供商停用狀態會繼續保留。

**現有設定：** 若先前已儲存衝突的排除規則，請重新取得模型、套用選擇並儲存，以清除自動產生的衝突規則。

## v0.2.100 更新內容

### 新增

- 新增統一的憑證設定視窗，可集中調整模型前綴、代理伺服器位址、優先順序、排程權重、指數冷卻、WebSockets、排除模型、自訂請求標頭及備註。儲存時僅更新已修改的欄位，關閉前會提醒尚未儲存的變更。
- 憑證卡片新增請求統計，顯示成功與失敗次數；核心提供近期資料時，可查看最近 200 分鐘的成功率，以及每 10 分鐘的請求明細。
- 新增憑證狀態與冷卻詳情，可查看異常原因、憑證或模型層級的冷卻倒數、HTTP 狀態及預計冷卻截止時間。倒數以核心提供的資料為依據，結束後可重新整理清單確認最新狀態。
- 憑證管理頁新增 Codex 額度重設入口，在支援重設且有可用次數時，可直接從卡片操作，並查看與額度頁一致的確認提示及操作結果。

### 優化

- 憑證清單改為隨視窗大小調整的卡片版面，使用進度條顯示剩餘額度，集中呈現重設時間、訂閱及重設次數資訊；備註移至操作按鈕上方，方便瀏覽與管理多個帳號。
- 統一介面的字級、字重與行高，改善不同語言的字型選擇，以及憑證卡片、對話框和使用記錄表格的文字層級。
- 提升淺色與深色主題下的文字對比度，讓輔助說明、輸入欄位的預留位置提示及表格內容更清晰易讀。

### 修正

- 修正憑證設定及啟停操作錯誤地作用於 API 接入或執行階段項目的問題，僅允許操作 OAuth 憑證檔案；OAuth 模型停用的管道清單也僅顯示對應憑證的管道，並明確提示其不影響 API 接入。
- 修正 macOS 等使用 WebKit 的環境中，智慧代理的模型選擇器在點選選項時提前收合，導致模型選擇失敗的問題。
- 修正 macOS 選單列圖示未遵循系統顯示與隱藏設定的問題，支援儲存圖示的顯示狀態。
