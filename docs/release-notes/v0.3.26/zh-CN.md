## v0.3.26 发布说明

- 关于该项目欢迎在群聊或 GitHub 提出建议与问题。
- 本版本修复 API 密钥停用导致配置无法加载的问题，并完善 Claude Code 模型管理和使用记录界面。

## 新增

- Claude Code 可分别选择是否由 CPA 管理启动模型和 Subagent 模型。关闭后不再覆盖 Claude Code 自己保存的默认模型；未指定模型的 Subagent 会继承主会话模型。

## 优化

- 使用记录的筛选菜单按选项内容调整宽度。
- Token 与请求切换改为与首页协议选择相同的样式。
- 凭证设置中的模型名称恢复为可搜索列表，输入时按该凭证的模型 ID 过滤。

## 修复

- 停用 Codex、Claude、Gemini 等原生 API 密钥时，不再写入内核不支持的 `disabled` 字段，避免整份配置无法加载。
- 已有配置会在内核启动前自动修复，无需手动修改。OpenAI 兼容接入仍使用原来的停用开关。
