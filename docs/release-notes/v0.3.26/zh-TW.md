## v0.3.26 發布說明

- 關於本專案，歡迎在群組聊天或 GitHub 提出建議與問題。
- 本版本修復停用 API 金鑰導致設定無法載入的問題，並完善 Claude Code 模型管理與使用記錄介面。

## 新增

- Claude Code 可分別選擇是否由 CPA 管理啟動模型與 Subagent 模型。關閉後不再覆寫 Claude Code 自行儲存的預設模型；未指定模型的 Subagent 會繼承主要工作階段模型。

## 改善

- 使用記錄的篩選選單會依選項內容調整寬度。
- Token 與請求切換改為與首頁協定選擇相同的樣式。
- 憑證設定中的模型名稱恢復為可搜尋清單，輸入時依該憑證的模型 ID 篩選。

## 修復

- 停用 Codex、Claude、Gemini 等原生 API 金鑰時，不再寫入核心不支援的 `disabled` 欄位，避免整份設定無法載入。
- 既有設定會在核心啟動前自動修復，無需手動修改。OpenAI 相容接入仍使用原本的停用開關。
