## v0.3.26 リリースノート

- このプロジェクトについてのご提案や問題の報告は、グループチャットまたは GitHub でお知らせください。
- API キーを無効にすると設定全体を読み込めなくなる問題を修正し、Claude Code のモデル管理と使用量記録の画面を改善しました。

## 追加

- Claude Code で、起動モデルと Subagent モデルを CPA が管理するかどうかを個別に選べるようになりました。オフにすると、Claude Code が保存した既定モデルを上書きせず、モデル未指定の Subagent はメインセッションのモデルを継承します。

## 改善

- 使用量記録のフィルターメニューが、選択肢の内容に合わせて幅を調整するようになりました。
- Token とリクエストの切り替えを、ホームのプロトコル選択と同じスタイルにしました。
- 認証情報設定のモデル名が再び検索可能な一覧になり、入力中はその認証情報のモデル ID で絞り込まれます。

## 修正

- Codex、Claude、Gemini などのネイティブ API キーを無効にしても、コアが対応していない `disabled` フィールドを書き込まなくなり、設定全体の読み込み失敗を防ぎます。
- 既存の設定はコア起動前に自動で修復されるため、手動での修正は不要です。OpenAI 互換プロバイダーは従来の無効化スイッチを引き続き使用します。
