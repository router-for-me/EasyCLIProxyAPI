## v0.3.27 發布說明

- 歡迎在群組或 GitHub 提出建議與問題。
- 本版本新增 Oh My Pi 支援，完善 Claude Code 設定，並提升配額資訊與桌面介面的穩定性。

## 新增

- 透過 OpenAI Responses API 新增 Oh My Pi 託管支援。CPA 會動態探索可用模型，寫入託管 provider 與模型設定，並在套用及還原設定時保留 Oh My Pi 原有檔案。
- 新增持久化桌面主題設定，支援淺色、深色及跟隨系統。

## 優化

- Claude Code 模型設定與其模型結構一致，支援分別設定啟動模型與 Subagent 模型、按角色設定模型，以及為各角色啟用 1M 上下文。
- Claude Code 執行時設定可以正確保存；停用託管或還原設定時會安全清理託管內容。
- 改進 Grok 配額計算，分別處理週度與月度用量，更準確識別訂閱等級，並在介面提供時顯示預付餘額。
- 使用記錄列高改為隨內容自適應；憑證卡片與操作控制項更加緊湊，避免內容重疊。
- 內建 CLIProxyAPI 核心更新至 **8.0.20**。

## 修復

- 修復 Claude Code 模型選擇器與憑證配額面板可能出現內容重疊或資訊不完整的問題。
- 修復 Grok 配額非同步補充訂閱資訊時覆蓋較新配額結果的問題。
- 憑證操作按鈕改用中性色彩樣式，狀態回饋更加清晰。
