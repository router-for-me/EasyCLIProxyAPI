## v0.3.27 リリースノート

- ご提案や問題の報告は、コミュニティチャットまたは GitHub からお寄せください。
- 本リリースでは Oh My Pi に対応し、Claude Code の設定を大幅に改善しました。クォータ情報とデスクトップ UI の安定性も向上しています。

## 追加

- OpenAI Responses API を通じた Oh My Pi の管理に対応しました。CPA は利用可能なモデルを動的に検出し、管理用 provider とモデル設定を適用します。元の Oh My Pi 設定はバックアップおよび復元できます。
- デスクトップのテーマ設定を保存できるようになりました。ライト、ダーク、システム連動に対応しています。

## 改善

- Claude Code のモデル設定を実際のモデル構成に合わせ、起動モデルと Subagent モデルを個別に設定できるようにしました。役割ごとのモデル割り当てと 1M コンテキストにも対応しています。
- Claude Code の実行時設定が正しく保存され、管理を無効化または設定を復元するときに管理対象の内容を安全に整理します。
- Grok のクォータ計算を改善し、週次と月次の使用量を正しく分離しました。契約プランの判定精度を高め、利用可能な場合は前払い残高も表示します。
- 使用記録の行高を内容に合わせて自動調整し、認証情報カードと操作コントロールを整理して重なりを防ぎました。
- 同梱の CLIProxyAPI コアを **8.0.20** に更新しました。

## 修正

- Claude Code のモデル選択欄と認証情報のクォータパネルで、内容が重なったり情報が欠落したりする問題を修正しました。
- Grok のクォータにサブスクリプション情報を追加する処理が、より新しいクォータ結果を上書きする問題を修正しました。
- 認証情報の操作ボタンをニュートラルな配色に変更し、状態をより分かりやすくしました。
