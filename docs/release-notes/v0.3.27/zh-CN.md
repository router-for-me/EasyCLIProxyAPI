## v0.3.27 发布说明

- 欢迎在群聊或 GitHub 提出建议与问题。
- 本版本新增 Oh My Pi 支持，完善 Claude Code 配置，并提升配额信息和桌面界面的稳定性。

## 新增

- 通过 OpenAI Responses API 新增 Oh My Pi 托管支持。CPA 会动态发现可用模型，写入托管 provider 和模型配置，并在应用和恢复配置时保留 Oh My Pi 原有文件。
- 新增持久化桌面主题设置，支持浅色、深色和跟随系统。

## 优化

- Claude Code 模型设置与其模型结构保持一致，支持分别配置启动模型和 Subagent 模型、按角色配置模型，以及为各角色启用 1M 上下文。
- Claude Code 运行时设置可以正确保存；关闭托管或恢复配置时会安全清理托管内容。
- 改进 Grok 配额计算，分别处理周度和月度用量，更准确识别订阅等级，并在接口提供时显示预付余额。
- 使用记录行高改为随内容自适应；凭证卡片和操作控件更加紧凑，避免内容重叠。
- 内置 CLIProxyAPI 内核更新至 **8.0.20**。

## 修复

- 修复 Claude Code 模型选择器和凭证配额面板可能出现内容重叠或信息不完整的问题。
- 修复 Grok 配额异步补充订阅信息时覆盖更新配额结果的问题。
- 凭证操作按钮改用中性色样式，状态反馈更加清晰。
