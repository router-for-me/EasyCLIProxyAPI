## 新增

- **預覽通道與版本比對**：版本頁新增隱藏的預覽通道切換，連續點擊應用程式 Logo 5 次即可在「正式版」與「預覽版」之間切換，切換後立刻依新通道重新檢查更新；預覽版的版本頁以建置時間為第一指標，並同時顯示「目前安裝建置時間」與「最新建置時間」，方便判斷是否需要更新。預覽建置的版本號帶時間戳，連續多次發佈也能分清先後。
- **預覽版應用程式內更新**：預覽版不再依賴本機標記檔案，可以直接透過應用程式內更新取得新的預覽建置；已安裝預覽版時也允許重複安裝預覽版，避免反覆手動下載安裝包。

## 優化與修復

- **OpenCode 圖片與附件貼上**：為 OpenCode 設定中產生的自訂 provider 模型補充 `attachment` 與 `modalities` 中繼資料，多模態模型宣告 `text`、`image`、`pdf` 輸入能力，圖像生成模型額外宣告 `image` 輸出能力。先前自訂 provider 缺少這些宣告時，OpenCode 會把模型當作純文字，在請求送出前就攔截剪貼簿圖片貼上與 PDF 附件（#567）。
- **預覽版更新通道修復**：修復預覽版在 GitCode 來源上錯誤取得正式版最新版本資訊的問題；修復預覽版更新清單引用非版本化檔名導致驗證失敗的問題；更新後端現在能正確解析預覽通道的標籤。
- **內建核心版本管理**：手動安裝的核心版本在冷啟動後不再被內建版本自動覆蓋；新增內建核心版本自動同步腳本，發佈流程會在建置前核對並同步內建核心版本（目前為 8.0.52），避免內建核心長期落後於上游。
