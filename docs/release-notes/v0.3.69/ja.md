## 新機能

- **プレビューチャンネルとビルド比較**：バージョンページに隠し機能としてプレビューチャンネルの切り替えを追加しました。アプリのロゴを 5 回続けてクリックすると「正式版」と「プレビュー版」を切り替えられ、切り替え直後に新しいチャンネルで更新を再確認します。プレビュー版のバージョンページではビルド時間を第一の指標とし、「現在インストールされているビルド時間」と「最新のビルド時間」を並べて表示するため、更新が必要かひと目で判断できます。プレビュービルドのバージョン番号にはタイムスタンプが付き、連続して公開しても前後関係が分かります。
- **プレビュー版のアプリ内更新**：プレビュー版はローカルのマーカーファイルに依存せず、アプリ内アップデートから新しいプレビュービルドを取得できるようになりました。プレビュー版をインストール済みの状態でも再インストールできるため、毎回手動でパッケージをダウンロードする必要がありません。

## 改善と修正

- **OpenCode の画像・添付ファイル貼り付け**：OpenCode 設定で生成されるカスタムプロバイダーのモデルに `attachment` と `modalities` のメタデータを追加しました。マルチモーダルモデルは `text`・`image`・`pdf` の入力に対応し、画像生成モデルはさらに `image` 出力にも対応することを宣言します。これまでカスタムプロバイダーにこれらの宣言がなかったため、OpenCode はモデルをテキスト専用として扱い、リクエストが送信される前にクリップボードの画像貼り付けや PDF 添付をブロックしていました（#567）。
- **プレビュー版の更新チャンネル修正**：プレビュー版が GitCode の配信元から正式版の最新バージョン情報を誤って取得していた問題を修正しました。プレビュー版の更新マニフェストがバージョン付きでないファイル名を参照して検証に失敗する問題も修正し、更新バックエンドがプレビューチャンネルのタグを正しく解決できるようにしました。
- **同梱コアのバージョン管理**：手動でインストールしたコアバージョンが、コールドスタート後に同梱版で上書きされないようになりました。同梱コアのバージョンを自動同期するスクリプトを追加し、リリースビルドの前に同梱コアのバージョン（現在は 8.0.52）を確認・同期するため、同梱コアが上流から取り残されることがなくなります。
