## 新增

- **预览通道与版本对比**：版本页新增隐藏的预览通道切换，连续点击应用 Logo 5 次即可在「正式版」与「预览版」之间切换，切换后立刻按新通道重新检查更新；预览版的版本页以构建时间为第一指标，并同时展示「当前安装构建时间」与「最新构建时间」，方便判断是否需要更新。预览构建的版本号带时间戳，连续多次发布也能分清先后。
- **预览版应用内更新**：预览版不再依赖本地标记文件，可以直接通过应用内更新获取新的预览构建；已安装预览版时也允许重复安装预览版，避免反复手动下载安装包。

## 优化与修复

- **OpenCode 图片与附件粘贴**：为 OpenCode 配置中生成的自定义 provider 模型补充 `attachment` 与 `modalities` 元数据，多模态模型声明 `text`、`image`、`pdf` 输入能力，图像生成模型额外声明 `image` 输出能力。此前自定义 provider 缺少这些声明时，OpenCode 会把模型当作纯文本，在请求发出前就拦截剪贴板图片粘贴与 PDF 附件（#567）。
- **预览版更新通道修复**：修复预览版在 GitCode 源上错误获取正式版最新版本信息的问题；修复预览版更新清单引用非版本化文件名导致校验失败的问题；更新后端现在能正确解析预览通道的标签。
- **内置内核版本管理**：手动安装的内核版本在冷启动后不再被内置版本自动覆盖；新增内置内核版本自动同步脚本，发布流程会在构建前核对并同步内置内核版本（当前为 8.0.52），避免内置内核长期落后于上游。
