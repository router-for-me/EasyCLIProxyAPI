## v0.3.25 發布說明

- 本版本持續完善使用記錄與憑證設定。歡迎在群組聊天或 GitHub 提出建議與問題回報。

## 改善

- 使用記錄的模型、服務供應商、來源、金鑰與結果篩選改為固定寬度的選擇選單，並移除多餘邊框與綠色聚焦光暈。
- 切換篩選條件時保留目前頁面，不再整頁重建。
- 請求記錄底部將筆數統計與顯示欄位、重設欄寬、匯出操作歸於一側，分頁控制項則獨立排列。
- 單一憑證的模型別名改為直接填寫模型名稱與別名；顯示名稱、保留原始模型、改寫回應模型名稱等選項收進展開區域。
- 關閉憑證設定時直接放棄尚未儲存的修改，不再顯示確認提示。
- 內建 CLIProxyAPI 核心升級至 **8.0.16**。
