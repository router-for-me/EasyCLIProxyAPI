## v0.3.25 发布说明

- 本版本继续完善使用记录和凭证设置。如果您遇到问题或有改进建议，欢迎在群聊或 GitHub 提出。

## 优化

- 使用记录的模型、服务商、来源、密钥和结果筛选改为固定宽度的选择菜单，去掉多余边框和绿色聚焦光晕。
- 切换筛选条件时保留当前页面，不再整页重建。
- 请求记录底部将条数统计与显示列、重置列宽、导出操作归到一侧，分页控件单独排列。
- 单个凭证的模型别名改为直接填写模型名称和别名；显示名称、保留原始模型、响应名称改写等选项收进展开区域。
- 关闭凭证设置时直接放弃未保存的修改，不再弹出确认。
- 内置 CLIProxyAPI 内核升级至 **8.0.16**。
