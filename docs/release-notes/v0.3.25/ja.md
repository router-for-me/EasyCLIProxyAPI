## v0.3.25 リリースノート

- 使用量記録と認証情報の設定を引き続き改善しました。ご提案や問題の報告は、グループチャットまたは GitHub でお知らせください。

## 改善

- 使用量記録のモデル、プロバイダー、ソース、キー、結果のフィルターを固定幅の選択メニューに変更し、余分な枠線と緑色のフォーカス表示を取り除きました。
- フィルターを変更しても現在の画面を維持し、ページ全体を再構築しないようにしました。
- リクエスト記録の下部で、件数表示と列の表示、列幅のリセット、エクスポート操作をまとめ、ページ切り替えは別に配置しました。
- 個別の認証情報のモデル別名は、モデル名と別名を直接入力するようにしました。表示名、元のモデルの保持、応答モデル名の書き換えは、展開する項目にまとめました。
- 認証情報の設定を閉じると、未保存の変更を確認なしで破棄するようにしました。
- 同梱の CLIProxyAPI コアを **8.0.16** に更新しました。
