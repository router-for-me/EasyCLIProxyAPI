## v0.3.21 發布說明
## 新增

- 新增外掛管理與外掛商店，支援安裝、更新、選擇版本、啟用與停用、解除安裝及編輯設定，並整合外掛提供的 OAuth 授權。
- 新增 Muse（Meta）OAuth 裝置授權；支援在 Windows 上偵測並啟動 DeepSeek Harness Desktop。
- 支援自訂 Codex 模型的系統提示詞，儲存後同步至模型目錄，並可還原模型預設值。
- 新增批次模型健康檢查；請求記錄顯示實際回應模型，並提示請求模型與回應模型不一致的情況。
- 請求記錄新增單次請求費用估算與 CSV 匯出，預設顯示推理等級，方便核對用量與排查問題。

## 改善

- 內建 CLIProxyAPI 核心升級至 **8.0.13**，管理介面與設定編輯適配 v8。
- 重新設計首頁、用量分析及主要管理頁面，統一淺色主題、導覽與表格樣式，改善深色模式對比度及窄視窗版面。
- 憑證管理改為精簡列表，集中顯示方案、狀態、請求統計與配額，支援分頁、啟用與停用及展開詳細資料，並完善冷卻倒數與重設操作。
- 進階設定新增更多結構化設定項目，涵蓋請求、OAuth、外掛、並行處理與服務供應商設定；完善搜尋、驗證、衝突提示、還原預設值及重新啟動提示。
- API 接入支援 v8 原生服務供應商群組，以及逐筆憑證編輯、刪除與排序，模型別名改於獨立分頁顯示。
- 用戶端列表支援搜尋、分頁及儲存顯示偏好，擴充安裝路徑偵測並優先顯示已安裝的用戶端。
- 版本管理提供「安裝內建核心」，可直接使用應用程式隨附的本機核心套件。

## 修正

- 修正 v7 升級至 v8 及混合格式設定的遷移問題，改善金鑰、服務供應商、模型別名、自訂欄位等設定的保留，並避免外部重新整理覆蓋尚未儲存的設定草稿。
- 修正不同帳號的同名憑證冷卻狀態混淆，以及更新 OAuth 模型排除設定時影響其他服務供應商的問題。
- 修正混合統計不同上下文長度請求時的費用彙總，改善費用估算涵蓋範圍的顯示。
- 修正模型別名來源驗證與 Codex 模型 ID 使用不一致的問題，並在重建可攜版時保留已安裝的外掛及執行資料。
