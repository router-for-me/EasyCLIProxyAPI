## 新增

- **敏感詞替換規則**：新增敏感詞頁面，可維護依供應商分組的原文替換、混淆詞與系統提示詞行過濾規則，儲存後立即寫入核心設定生效。
- **一鍵加入雲端最新規則**：支援從 GitHub 儲存庫取得官方規則檔案，只補上本機缺少的詞條，重複點擊不會重複加入。

## 改進

- **雲端規則合併**：匯入時保留目前尚未儲存的修改，匯入完成後自動儲存合併結果；下載失敗或檔案無效時維持現有設定不變，儲存失敗則保留合併內容並提示錯誤，方便再次儲存。
- **規則檔案說明**：新增規則檔案格式文件，說明各供應商欄位、條目上限與本機修改方式。

## 修正

- **GitHub 權杖驗證**：取得雲端規則時重用設定中的 GitHub 存取權杖，留空時改用 `GITHUB_TOKEN` 環境變數，並遵循應用程式代理設定。
- **權杖傳送範圍**：權杖只傳送給 GitHub API，不會隨公開 Raw 下載或重新導向位址外流；API 請求失敗時再回退到公開檔案。
