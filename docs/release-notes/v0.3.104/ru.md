## Добавлено

- **Правила замены конфиденциальных слов**: Добавлена страница конфиденциальных слов с правилами замены исходного текста, обфускации слов и фильтрации строк системного промпта по провайдерам. После сохранения правила сразу записываются в конфигурацию ядра.
- **Добавление актуальных облачных правил в один клик**: Официальный файл правил загружается из репозитория GitHub, и добавляются только отсутствующие локально записи; повторные нажатия не создают дубликатов.

## Улучшено

- **Объединение облачных правил**: При импорте сохраняются текущие несохранённые изменения, а объединённый результат сохраняется автоматически. При ошибке загрузки или неверном файле текущая конфигурация остаётся прежней; при ошибке сохранения объединённые данные сохраняются и показывается сообщение для повторной попытки.
- **Документация формата правил**: Добавлено описание полей по провайдерам, ограничений на количество записей и порядка локального редактирования.

## Исправлено

- **Авторизация токеном GitHub**: При загрузке облачных правил используется токен доступа GitHub из настроек, при пустом значении — переменная окружения `GITHUB_TOKEN`; учитываются настройки прокси приложения.
- **Область отправки токена**: Токен отправляется только в GitHub API и не передаётся при загрузке публичного Raw-файла или по адресам перенаправления; публичный файл используется только как запасной вариант при ошибке API.
