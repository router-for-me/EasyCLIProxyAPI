## 新增

- **敏感词替换规则**：新增敏感词页面，可维护按供应商分组的原文替换、混淆词与系统提示词行过滤规则，保存后立即写入核心配置生效。
- **一键添加云端最新规则**：支持从 GitHub 仓库拉取官方规则文件，只补充本地缺少的词条，重复点击不会重复添加。

## 改进

- **云端规则合并**：导入时保留当前未保存的修改，导入完成后自动保存合并结果；下载失败或文件无效时保持现有配置不变，保存失败则保留合并内容并提示错误，便于再次保存。
- **规则文件说明**：新增规则文件格式文档，说明各供应商字段、条目上限与本地修改方式。

## 修复

- **GitHub 令牌鉴权**：拉取云端规则时复用设置中的 GitHub 访问令牌，留空时回退到 `GITHUB_TOKEN` 环境变量，并遵循应用代理设置。
- **令牌发送范围**：令牌只发送给 GitHub API，不会随公开 Raw 下载或重定向地址外发；API 请求失败时再回退到公开文件。
