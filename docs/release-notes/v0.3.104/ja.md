## 追加

- **機密ワード置換ルール**：機密ワードのページを追加し、プロバイダーごとに原文の置換、難読化ワード、システムプロンプトの行フィルターを管理できるようにしました。保存するとコア設定に反映され、すぐに有効になります。
- **クラウド最新ルールのワンクリック追加**：GitHub リポジトリから公式ルールファイルを取得し、ローカルにない項目だけを追加します。繰り返しクリックしても重複しません。

## 改善

- **クラウドルールのマージ**：インポート時に未保存の変更を保持し、完了後にマージ結果を自動保存します。ダウンロード失敗やファイルが無効な場合は既存設定を変更せず、保存に失敗した場合はマージ内容を残してエラーを表示し、再保存できます。
- **ルールファイルの説明**：プロバイダー別のフィールド、項目数の上限、ローカルでの編集方法をまとめた形式ドキュメントを追加しました。

## 修正

- **GitHub トークン認証**：クラウドルール取得時に設定の GitHub アクセストークンを再利用し、空の場合は `GITHUB_TOKEN` 環境変数を使用して、アプリのプロキシ設定にも従います。
- **トークンの送信範囲**：トークンは GitHub API にのみ送信し、公開 Raw のダウンロードやリダイレクト先には送信しません。API リクエストに失敗した場合のみ公開ファイルにフォールバックします。
