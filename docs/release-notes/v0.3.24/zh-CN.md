## v0.3.24 发布说明

- 本版本继续完善使用记录和内核配置管理。如果您遇到问题或有改进建议，欢迎在群聊或 GitHub 提出。

## 新增

- 使用记录新增“显示设置”：可以选择要显示的列，并可开启“固定记录行高”。开启后可拖动滑块调整行高，关闭时记录会根据内容自动适应。
- 使用记录的分页、显示列和列宽等偏好会保存到软件数据目录，应用更新后会自动恢复。

## 优化

- 管理密钥相关文案统一为“管理密钥”和“网页管理后台”，中、英、日语言保持同步。
- 管理密钥设置在读取失败或无法恢复可用明文密钥时使用 `123456` 作为恢复值，并同步软件请求和内核配置，避免两边使用不同的密钥。
- 使用记录底部工具栏改进为更清晰的“显示列”和“重置列宽”操作。

## 修复

- 修复内核 v8 已将管理密钥写成 bcrypt/argon2 哈希后，GUI 启动时再次写入明文导致配置渲染异常的问题。
- 修复部分合法 v8 配置在启动时生成重复顶层 `management` 节点、导致内核无法启动的问题（[Issue #351](https://github.com/router-for-me/EasyCLIProxyAPI/issues/351)）。
- 修复使用记录设置在应用更新后恢复为默认值的问题。
