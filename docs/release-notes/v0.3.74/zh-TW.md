## 新增

- **MCP 與技能條目可同步到 OpenClaw**：MCP 伺服器與 Agent 技能現在可以寫入 OpenClaw 設定，不用再手工複製一份。
- **Codex 模型目錄可自訂順序**：模型清單支援拖曳調整順序，排序結果會儲存並在下次啟動時還原。
- **憑證標籤批次管理**：支援一次為多個憑證設定、清除或沿用標籤，批次選取時會保留原有標籤，不會把不可編輯的項目混進來。
- **z.ai Coding Plan 額度查詢**：新增 z.ai Coding Plan 的額度檢視，支援每週視窗與團隊視窗。
- **語意模型路由（選用）**：可以依模型語意選擇上游，預設關閉，開啟前會先驗證路由可用性。
- **套用設定方案前先確認**：點擊「套用方案」會先跳出確認視窗，逐條列出即將寫入的變更。
- **自訂 CLI 啟動參數**：支援為核心設定額外的啟動參數，並保留指令碼執行原則。
- **預覽通道改為依時間戳發布**：每次預覽建置使用獨立的時間戳發布，保留最近 8 個，用戶端自動取最新一個；下載通道說明也區分了預覽版與正式版。
- **補齊核心 v8 設定項**：設定頁補上了先前缺少的核心選項，並依用途重新分類。

## 修復

- **MCP 新增伺服器彈窗版面異常**：彈窗表單區曾被壓縮到只剩一條窄縫，伺服器名稱與啟動指令藏在捲動區下方，底部按鈕被拉長。現在表單區高度正常，所有欄位一次可見。
- **啟用反向代理後重新啟動失效**：關閉反向代理再重新啟動，開關會自己變回啟用；現在會正確儲存並還原，重新啟動提示標記也不會被後續寫入清除。
- **主介面 WebView 異常**：主瀏覽器結束後，內嵌頁面可能變空白；現在會還原主 WebView 與子 WebView，核心狀態未知時也不會誤清空。
- **Copilot 用量統計**：不再把 CLI 設定裡的註解與無法解析的 JSON 當成錯誤，也不會把已失效的工作階段重複計入。
- **Claude 雲端額度顯示**：區分雲端額度餘額與其他額度，不再混在一起顯示。
- **每金鑰 Token 統計**：還原依金鑰統計的 Token 檢視。
- **GitCode 回退位址**：未設定 GitCode 時不再嘗試使用其回退位址（Refs #548）。
- **企業根憑證**：處理 #408 時改為信任系統原生的企業根憑證。
- **路由驗證失敗提示**：路由方案驗證不通過時，會直接顯示失敗原因，而不是靜默回退。
- **發行說明多語順序**：發行說明現在依 en、zh-CN、zh-TW、ja 的順序輸出四種語言。

## 優化

- **MCP 與技能頁面**：載入失敗時顯示行內錯誤提示與空狀態，不再一片空白；清單間距與版面也做了打磨。
- **反向代理設定卡片**：改為存取路徑摘要加保護狀態的版面，設定項分組更清楚。
