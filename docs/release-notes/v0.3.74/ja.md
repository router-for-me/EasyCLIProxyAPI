## 追加

- **MCP サーバーとスキルを OpenClaw へ同期**：MCP サーバーとエージェントスキルのエントリを、手作業でコピーせずに OpenClaw 設定へ書き込めるようになりました。
- **Codex モデル一覧の並び順をカスタマイズ**：モデル一覧を並べ替えでき、順序は保存されて次回起動時に復元されます。
- **認証情報タグの一括管理**：複数の認証情報にまとめてタグを設定・解除・継承できます。既存のタグは保持され、編集できない項目は選択対象から除かれます。
- **z.ai Coding Plan のクォータ表示**：週次のウィンドウとチームのウィンドウを含む z.ai Coding Plan のクォータを確認できます。
- **任意のセマンティックモデルルーティング**：モデルの意味に応じて上流を選べます。既定では無効で、有効化前にルーティング経路を検証します。
- **ルーティング案の適用前に確認**：適用時に確認ダイアログが開き、これから書き込む変更を一覧で示します。
- **CLI 起動引数のカスタマイズ**：コアに追加の起動引数を指定でき、スクリプト実行ポリシーも保持されます。
- **プレビューをタイムスタンプ付きで公開**：プレビュービルドごとにタイムスタンプ付きリリースを公開し、最新 8 件を保持します。クライアントは最新のものを自動で選びます。ダウンロードチャネルの説明もプレビュー版と正式版で区別されました。
- **コア v8 の設定項目を補完**：これまで欠けていたコア設定を設定ページに追加し、用途ごとに整理しました。

## 修正

- **MCP サーバー追加ダイアログのレイアウト崩れ**：フォーム領域が細い帯状に潰れ、サーバー名と起動コマンドが小さなスクロール領域の下に隠れ、下部ボタンが引き伸ばされていました。現在はフォーム領域が正常な高さになり、すべての項目が一度に表示されます。
- **リバースプロキシの状態が再起動で失われる**：無効にして再起動するとスイッチが有効に戻っていました。現在は状態が保存・復元され、再起動が必要というマーカーも後続の書き込みで消えません。
- **メイン WebView 終了後に埋め込みページが空白になる**：メインと子の WebView が復帰するようになり、コアの状態が不明なときも消去されません。
- **Copilot の使用量集計**：CLI 設定のコメントや解析できない JSON をエラーとして扱わなくなり、無効になったセッションを二重に数えることもなくなりました。
- **Claude のクラウドクレジット表示**：クラウド残高を他のクレジット数値と分けて表示します。
- **キーごとのトークン統計**：キーごとのトークン表示を復元しました。
- **GitCode のフォールバック URL**：未設定の GitCode へフォールバック要求を送らなくなりました（Refs #548）。
- **企業ルート証明書**：#408 ではシステム標準の企業ルート証明書を信頼します。
- **ルーティング検証の失敗表示**：ルーティング案が検証で拒否されたとき、黙ってフォールバックせず失敗理由を表示します。
- **リリースノートの言語順序**：リリースノートは en、zh-CN、zh-TW、ja の順で出力されます。

## 改善

- **MCP とスキルのページ**：読み込みに失敗したとき、空白ではなくインラインのエラー表示と空状態を示します。一覧の余白とレイアウトも調整しました。
- **リバースプロキシ設定カード**：アクセス経路の概要と保護状態を並べたレイアウトに変更し、項目のまとまりを分かりやすくしました。
