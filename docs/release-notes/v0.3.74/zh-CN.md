## 新增

- **MCP 与技能条目可同步到 OpenClaw**：MCP 服务器与 Agent 技能现在可以写入 OpenClaw 配置，不用再手工复制一份。
- **Codex 模型目录可自定义顺序**：模型列表支持拖动调整顺序，排序结果会保存并在下次启动时恢复。
- **凭据标签批量管理**：支持一次为多个凭据设置、清除或沿用标签，批量选择时会保留原有标签，不会把不可编辑的项混进来。
- **z.ai Coding Plan 额度查询**：新增 z.ai Coding Plan 的额度查看，支持每周窗口与团队窗口。
- **语义模型路由（可选）**：可以按模型语义选择上游，默认关闭，开启前会先验证路由可用性。
- **应用配置方案前先确认**：点击「应用方案」会先弹出确认窗口，逐条列出即将写入的改动。
- **自定义 CLI 启动参数**：支持为内核配置额外的启动参数，并保留脚本执行策略。
- **预览通道改为按时间戳发布**：每次预览构建使用独立的时间戳发布，保留最近 8 个，客户端自动取最新一个；下载渠道说明也区分了预览版与正式版。
- **补齐核心 v8 配置项**：设置页补上了此前缺失的核心选项，并按用途重新归类。

## 修复

- **MCP 新建服务器弹窗布局异常**：弹窗表单区曾被压缩到只剩一条窄缝，服务器名称与启动命令藏在滚动区下方，底部按钮被拉伸。现在表单区高度正常，所有字段一次可见。
- **开启反向代理后重启失效**：关闭反向代理再重启，开关会自己变回启用；现在会正确保存并恢复，重启提示标记也不会被后续写入清除。
- **主界面 WebView 异常**：主浏览器退出后，内嵌页面可能变空白；现在会恢复主 WebView 与子 WebView，内核状态未知时也不会误清空。
- **Copilot 用量统计**：不再把 CLI 配置里的注释和无法解析的 JSON 当成错误，也不会把已失效的会话重复计入。
- **Claude 云额度显示**：区分云额度余额与其他额度，不再混在一起显示。
- **每密钥 Token 统计**：恢复按密钥统计的 Token 视图。
- **GitCode 回退地址**：未配置 GitCode 时不再尝试使用其回退地址（Refs #548）。
- **企业根证书**：处理 #408 时改为信任系统原生的企业根证书。
- **路由校验失败提示**：路由方案校验不通过时，会直接显示失败原因，而不是静默回退。
- **发布说明多语言顺序**：发布说明现在按 en、zh-CN、zh-TW、ja 的顺序输出四种语言。

## 优化

- **MCP 与技能页面**：加载失败时显示行内错误提示与空状态，不再一片空白；列表间距与排版也做了打磨。
- **反向代理设置卡片**：改为访问路径摘要加保护状态的布局，配置项分组更清楚。
