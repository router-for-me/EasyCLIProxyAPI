## 修复

- **任务栏最小化后恢复黑屏**：在 Windows 上反复点击任务栏图标「最小化 → 恢复」时，窗口会出现约 0.3～1 秒的纯黑底色，或者只剩左上角一小条窗口按钮。现在最小化时不再摘除 WebView 控制器，既保持界面合成表面存活，也不让主视图被压缩成最小化时的图标尺寸，恢复时界面直接出现。
- **从托盘恢复窗口后界面状态不同步**：窗口从托盘还原时补一次可见性同步，避免恢复瞬间仍按最小化状态运行。

## 优化

- **窗口隐藏时停止无效轮询**：反向代理子页的状态查询、窗口恢复前的等待不再在窗口不可见时继续执行，最小化期间 CPU 占用明显下降。
- **内核状态探测与用量队列轮询降频**：内核就绪后状态探测间隔放宽到 10 秒，用量队列空闲时的轮询改为逐级退避，空闲时不再每秒访问内核。
