## Исправлено

- **Чёрный экран при восстановлении окна, свёрнутого с панели задач**: в Windows при многократном нажатии на значок на панели задач («свернуть → восстановить») окно на 0,3–1 секунды становилось полностью чёрным либо оставалась только тонкая полоса заголовка в левом верхнем углу. Теперь контроллер WebView не отсоединяется при сворачивании: поверхность композиции сохраняется, а основной вид не сжимается до размера значка, поэтому интерфейс появляется сразу при восстановлении.
- **Устаревшее состояние окна после восстановления из лотка**: при восстановлении из системного лотка состояние окна синхронизируется заново, поэтому приложение больше не продолжает работать так, будто окно свёрнуто.

## Улучшено

- **Без опроса впустую, пока окно скрыто**: запрос состояния обратного прокси и ожидание перед восстановлением больше не выполняются, когда окно не видно, что заметно снижает нагрузку на процессор при свёрнутом окне.
- **Реже опрашиваются состояние ядра и очередь использования**: после готовности ядра его состояние проверяется раз в 10 секунд, а опрос пустой очереди использования выполняется с постепенно растущим интервалом вместо ежесекундного обращения к ядру.
