## 修復

- **工作列最小化後還原黑畫面**：在 Windows 上反覆點擊工作列圖示「最小化 → 還原」時，視窗會出現約 0.3～1 秒的純黑底色，或者只剩左上角一小條視窗按鈕。現在最小化時不再卸除 WebView 控制器，既保持介面合成表面存活，也不讓主視圖被壓縮成最小化時的圖示尺寸，還原時介面直接出現。
- **從系統匣還原視窗後介面狀態不同步**：視窗從系統匣還原時補一次可見性同步，避免還原瞬間仍按最小化狀態執行。

## 優化

- **視窗隱藏時停止無效輪詢**：反向代理子頁的狀態查詢、視窗還原前的等待不再在視窗不可見時繼續執行，最小化期間 CPU 佔用明顯下降。
- **核心狀態探測與用量佇列輪詢降頻**：核心就緒後狀態探測間隔放寬到 10 秒，用量佇列閒置時的輪詢改為逐級退避，閒置時不再每秒存取核心。
