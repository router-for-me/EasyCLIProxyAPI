## 優化與修復

- 外掛 Logo 與圖示展示優化：已安裝外掛清單、外掛市場及 OAuth 登入頁支援展示外掛自帶的 Logo；同時修復了未內建圖示的第三方憑證會錯誤顯示為 Gemini 圖示的問題（#556）。
- 使用記錄模型匹配優化：針對帶有思考等級後綴（如 -high、-low）、日期版本號或 -build 標記的模型請求，不再錯誤標記為「模型被替換」（#551）。
- 應用程式更新安全回退機制：可攜版在自動更新後，會等待新版代理核心成功啟動並就緒後才清理舊版本備份；如果新版核心啟動失敗，將安全回滾，避免軟體更新後無法啟動（#555）。
- 設定同步保護：當直接匯入或讀取不含 auth-dir 或 api-keys 的精簡核心設定檔時，自動保留你在桌面用戶端設定的憑證目錄與帶有備註的 API 金鑰清單，不會被意外清空（#553）。
- Codex 智慧代理設定與工作階段修復：補充 OAuth 模型上下文大小與推理等級選項；修復切換 Provider 時 Codex 桌面端歷史工作階段未正確同步顯示的問題（#552、#554）。
