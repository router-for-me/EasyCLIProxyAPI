## 优化与修复

- 插件 Logo 与图标展示优化：已安装插件列表、插件市场及 OAuth 登录页支持展示插件自带的 Logo；同时修复了未内置图标的第三方凭据会错误显示为 Gemini 图标的问题（#556）。
- 使用记录模型匹配优化：针对带有思考等级后缀（如 -high、-low）、日期版本号或 -build 标识的模型请求，不再错误标记为“模型被替换”（#551）。
- 应用更新安全回退机制：便携版在自动更新后，会等待新版代理内核成功启动并就绪后才清理旧版本备份；如果新版内核启动失败，将安全回滚，避免软件更新后无法启动（#555）。
- 配置同步保护：当直接导入或读取不含 auth-dir 或 api-keys 的精简内核配置文件时，自动保留你在桌面客户端设置的凭据目录与带有备注的 API 密钥列表，不会被意外清空（#553）。
- Codex 智能体配置与会话修复：补充 OAuth 模型上下文大小与推理级别选项；修复切换 Provider 时 Codex 桌面端历史会话未正确同步显示的问题（#552、#554）。
