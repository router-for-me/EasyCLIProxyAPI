## 改善と不具合修正

- プラグインのロゴ・アイコン表示の改善：インストール済みプラグイン一覧、プラグインストア、および OAuth ログイン画面でプラグイン独自のロゴ表示に対応しました。また、専用アイコンを持たないサードパーティ製認証情報が誤って Gemini アイコンで表示される問題を修正しました（#556）。
- 使用記録におけるモデルマッチングの改善：思考レベルのサフィックス（-high や -low など）、日付付きバージョン、または -build 識別子が付いたモデルリクエストについて、誤って「モデルが置換されました」と判定されないよう改善しました（#551）。
- アプリ更新時の安全なロールバック機構：ポータブル版の自動更新時、新しいプロキシコアが正常に起動して準備完了するのを待ってから旧バージョンのバックアップを削除するようにしました。新コアの起動に失敗した場合は安全にロールバックし、更新後にアプリが起動できなくなるのを防ぎます（#555）。
- 設定同期の保護：auth-dir や api-keys を含まない軽量なコア設定ファイルを直接インポートまたは読み込んだ際、デスクトップクライアント側で設定済みの認証情報ディレクトリや備考付き API キー一覧が誤ってクリアされないよう自動で保護します（#553）。
- Codex エージェント設定およびセッションの修正：OAuth モデルのコンテキスト長と推論レベル（reasoning level）オプションを補完しました。また、Provider 切り替え時に Codex デスクトップ版の過去セッションが正しく同期・表示されない問題を修正しました（#552、#554）。
