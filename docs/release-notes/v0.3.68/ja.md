## 新機能

- **ローカル Agent 使用履歴とダッシュボードの刷新**：Agent の使用履歴をローカル SQLite データベース（`agent_usage.db`）に永続化し、高速な増分同期と長期履歴保存に対応しました。カスタム期間・集計粒度の切り替え、Agent 複数選択フィルター、Token・コスト・キャッシュヒット率の KPI カード（スパークラインおよび前期比較付き）、トレンドと Token 内訳チャート、アクティビティカード（全期間カレンダーおよび直近 30 日間の時間帯ヒートマップ）、モデル・Agent 別詳細テーブルを備えたダッシュボードに刷新しました。また、「データ管理」でバックグラウンド同期の間隔（5分〜1時間、または無効）を設定可能にしました（#564）。
