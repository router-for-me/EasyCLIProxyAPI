## Системные подсказки агентов

- Редактор системных подсказок доступен в основных настройках поддерживаемых агентов. Подсказка по умолчанию и переопределения для отдельных моделей настраиваются отдельно.
- Claude Code и Claude Desktop используют исходные подсказки, пока переопределения выключены. Отключение переопределений не удаляет сохранённые правила.
- В Codex подсказки по-прежнему редактируются для каждой модели в списке моделей. Сохранение или сброс настроек моделей ZCode больше не меняет сохранённые системные подсказки.
