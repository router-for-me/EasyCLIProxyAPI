## Prompts de sistema dos agentes

- Encontre os prompts de sistema em Configuração básica de cada agente compatível. O editor separa o padrão do agente das substituições individuais por modelo.
- O Claude Code e o Claude Desktop mantêm seus prompts originais a menos que as substituições estejam ativadas. É possível pausar as substituições sem excluir as regras salvas.
- O Codex continua editando os prompts por modelo em seu catálogo de modelos. Salvar ou restaurar as configurações de modelos do ZCode não altera mais seus prompts de sistema salvos.
