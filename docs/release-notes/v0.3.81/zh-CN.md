这个版本把 ECPA 精选插件页面第一眼就能用当作目标：页面一出现，卡片和安装按钮就可操作，不再先灰着等一连串初始化；插件装好之后立即显示「已安装」，有新版时显示「可更新」并可一键更新；插件商店接口暂时不可用时，页面改为用内置目录的数据兜底，不再整页灰按钮。内置内核同步升级到 8.0.59。

如果你在使用中遇到问题，请通过 [QQ群](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 反馈，我们会尽快处理。

## 优化

- **精选插件页打开即可操作**：卡片先用目录数据渲染，安装按钮只等插件清单返回，不再排在功能探测、插件源注册和版本查询之后。清单还没回来时按钮显示加载状态，而不是一个没有任何说明的灰按钮。
- **版本查询移到后台**：最新版本号在页面可用之后异步补齐，不会再让按钮在刷新版本的过程中重新变灰。

## 修复

- **安装成功后立即显示已安装**：以前装完要等插件清单重新刷新才变色，中途还会退回「安装」按钮。现在安装一成功卡片就显示「已安装」，并在本次会话内保持，不会再被过期清单覆盖。
- **已安装插件能显示可更新**：更新标记与「更新」按钮改为按已安装版本和目录最新版本比较得出，支持 `v` 前缀与预览版号，之前从其他来源装的插件也能识别并更新。
- **插件商店接口异常时不再整页灰按钮**：商店清单请求失败导致没有条目时，页面改为用目录里已有的插件信息合成可安装项，安装时先补注册插件源再重试一次，仍然失败会把错误显示出来，而不是让按钮静默不可点。
