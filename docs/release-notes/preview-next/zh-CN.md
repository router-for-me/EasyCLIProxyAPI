## 修复

- **稳定版切到预览通道后没有「立即升级」**：预览构建的版本号形如 `0.3.6-preview.20261106-1137`，按语义化版本规则永远低于 `0.3.6`，所以从正式版切到预览通道时，更新检查判定"没有新版本"，只剩一个下载按钮。现在预览通道下的时间戳构建会被正确识别为新版本，切换通道后即可直接应用内升级。
- **手动下载忽略了所选下载源**：桌面客户端的下载按钮直接用清单里的 GitHub 原始地址打开浏览器，选中的镜像源只用于拉取版本清单，真正下载包时没有生效。现在下载链接会按当前下载源套用镜像前缀，选 `ghfast.top` 或 `gh-proxy.com` 时下到的就是镜像地址。
