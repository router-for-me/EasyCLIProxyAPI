## 修正

- **プラグインが提供するモデルをマッピング元として使用可能に**：モデルマッピングは元モデルの取得元を組み込みの OAuth チャネルからのみ検索していたため、プラグインが追加した provider（豆包など）が提供するモデルは一致せず、カードに有効なアクセス元が見つからない旨が表示されていました。現在は組み込みチャネルに加えて、有効な認証情報と有効化済みプラグインが宣言した provider も照会するため、プラグインのモデルをそのままマッピングできます。
- **認証情報カードの操作ボタンが切れなくなりました**：操作行がカードより広い場合、削除などのボタンがカードの端で途切れていました。現在は両方のボタングループがカード幅の中で折り返し、展開状態や狭い段組みレイアウトでもすべての操作が残ります。
- **Antigravity セッションのモデル名を復元**：Antigravity の記録ファイルにはモデル情報が含まれないため、これらのセッションは使用状況で不明なモデルとして表示されていました。現在はセッションの設定変更テキストから実際のモデルを復元し、チャンクファイルに情報がない場合は同じセッションの完全な記録を参照します。
