## 修復

- **外掛提供的模型可以作為映射來源**：模型映射先前只會在內建的 OAuth 通道裡尋找原模型的來源，外掛新增的 provider（例如豆包）提供的模型一直匹配不到，卡片上會提示找不到有效的接入源。現在會同時查詢內建通道、有效憑證以及已啟用外掛宣告的 provider，外掛模型可以直接完成映射。
- **憑證卡片的操作按鈕不再被裁切**：操作列比卡片更寬時，刪除等按鈕會被卡片邊緣截斷。現在兩組按鈕會在卡片寬度內自動換行，展開狀態和較窄的分欄版面下也同樣保留全部操作。
- **Antigravity 工作階段的模型名稱恢復**：Antigravity 的紀錄檔本身不含模型欄位，過去這些工作階段在用量統計裡顯示為未知模型。現在會從工作階段的設定變更文字中還原真實模型，分塊檔案缺少該資訊時回退讀取同一工作階段的完整紀錄。
