## Added

- Local Agent Usage Statistics & Multi-source Session Scanning: Added a local agent usage page (`AgentUsageView`) that automatically scans and parses local session records from popular coding agents including Claude Code, Codex, Gemini CLI, Antigravity, OpenCode, Kimi Code, Pi, OMP, MCode, Copilot, and ZCode, with built-in directory depth limits and large-file protection; supports filtering by time range (today, last 24 hours, last 7 days, last 30 days, or all time) and source, with overview cards for total tokens, estimated total cost, input/output tokens, and cache hits/writes, plus daily breakdowns and model cost statistics ([#538](https://github.com/router-for-me/EasyCLIProxyAPI/pull/538)).
- Routing Orchestration & Real-time Routing Monitoring: Added a routing orchestration page and a real-time routing visualization dashboard, supporting routing policies, session affinity, failure retries, cooldown periods, and multi-tier key and credential weight orchestration, with live request distribution flows and cooldown countdowns.
- WSL Agent Configuration Directory Support: The Agents → Manage page now supports custom configuration directory paths for each agent, including local paths and WSL UNC paths on Windows such as `\\wsl$\Ubuntu\home\...` or `\\wsl.localhost\...`, with full underlying support for atomic writes, template previews, and backup restoration on WSL UNC paths ([#523](https://github.com/router-for-me/EasyCLIProxyAPI/issues/523)).
- Muse (Meta) Quota Queries: Added Muse (Meta) provider support to the quota query page, with automatic credential detection and queries for window-based quotas, weekly quotas, reset times, and plan information ([#496](https://github.com/router-for-me/EasyCLIProxyAPI/issues/496)).
- Specific Core Version Selection & Installation: The version management page now fetches and lets you select specific historical CPA core versions for installation, with prerelease labels and improved automatic fallback when fetching version lists from multiple download sources ([#528](https://github.com/router-for-me/EasyCLIProxyAPI/issues/528), [#539](https://github.com/router-for-me/EasyCLIProxyAPI/pull/539)).
- ZCode Model Capability Auto-calibration & Catalog Redesign: Added automatic calibration of ZCode model capabilities based on local invocation records, filtering out unsupported reasoning levels while providing the full list of thinking levels by default; redesigned the model catalog dialog as a unified Codex-style two-column editor and improved Codex CLI path detection ([#547](https://github.com/router-for-me/EasyCLIProxyAPI/pull/547)).

## Fixed

- Credential Tag Persistence & Batch Tagging Improvements: Fixed custom tags disappearing after refreshing the credential list by adding a local persistent tag merge layer; improved tag display and click-to-filter interactions on account cards, and added batch tag addition/removal and whole-group selection by tag in the batch management dialog ([#546](https://github.com/router-for-me/EasyCLIProxyAPI/issues/546)).
- Automatic Core Startup After Updates or Restarts & Port Detection Retries: Fixed upstream requests returning 502 when the core failed to start automatically after a core update or an automatic app upgrade and restart; added liveness checks and retries for temporarily occupied management ports during startup and process takeover, and improved the wording in the update confirmation dialog.
