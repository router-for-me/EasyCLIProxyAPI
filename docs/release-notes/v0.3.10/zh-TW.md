## 優化

- 適配最新版 ZCode 的 `.zcode/v2/provider_config.json` 設定格式，支援設定、辨識及還原代理連線與預設模型，並保留其他提供者設定。
- 每次進入「版本管理」頁面時自動檢查應用程式和核心更新，返回該頁面即可重新檢查。
- 提供者優先度支援負整數，並在儲存前驗證輸入範圍。
- 工作階段親和性 TTL 在儲存前驗證時長格式，支援 `30m`、`1h30m` 等寫法；留空使用預設值，小於 1 秒的有效值以 1 秒儲存。
- 核心 v8 管理介面報錯時，同時顯示錯誤類型和詳細原因，方便找出無效設定。

## 修復

- 修復 macOS 更新時 DMG 暫時被佔用、卸載失敗可能中斷更新的問題；卸載會重試，必要時延後清理。
- 修復核心 v8 提供者分組名稱和備註在讀取或儲存後可能遺失的問題；重複項目的判斷不再受分組名稱影響。
- 修復 DeepSeek 憑據因分組名稱寫入錯誤欄位而被核心拒絕儲存的問題。
- 修復編輯提供者時模型思考設定可能被覆蓋的問題：未修改思考等級時保留各模型原有設定，手動清空後不再還原舊值。
- 相容模型探索結果中的思考欄位，並移除舊的「測試模型」設定項目。
- 修復「停用冷卻」和 Claude 使用者 ID 快取在選擇關閉時未正確儲存的問題；現在可明確選擇使用預設值、啟用或停用。
- 修復核心 v8 設定中的空節點和新舊欄位混用可能導致 TLS、敏感詞等設定讀取或寫入異常的問題。
- 修正監聽位址、使用統計、重試次數和重試間隔等設定未配置時的顯示值，使其與核心實際行為一致。
- 修復 API 提供者編輯和模型選擇對話框在窄視窗或 macOS WebKit 下可能超出畫面、無法正常捲動的問題。
