## 优化

- 适配最新版 ZCode 的 `.zcode/v2/provider_config.json` 配置格式，支持设置、识别和恢复代理接入与默认模型，并保留其他提供方配置。
- 每次进入“版本管理”页面时自动检查软件和内核更新，返回该页面即可重新检查。
- 提供方优先级支持负整数，并在保存前校验输入范围。
- 会话亲和 TTL 在保存前校验时长格式，支持 `30m`、`1h30m` 等写法；留空使用默认值，小于 1 秒的有效值按 1 秒保存。
- 内核 v8 管理接口报错时，同时显示错误类型和详细原因，便于定位无效配置。

## 修复

- 修复 macOS 更新时 DMG 暂时被占用、卸载失败可能中断更新的问题；卸载会重试，必要时延后清理。
- 修复内核 v8 提供方分组名称和备注在读取或保存后可能丢失的问题；重复项判断不再受分组名称影响。
- 修复 DeepSeek 凭据因分组名称写入错误字段而被内核拒绝保存的问题。
- 修复编辑提供方时模型思考设置可能被覆盖的问题：未修改思考等级时保留各模型原有设置，手动清空后不再恢复旧值。
- 兼容模型发现结果中的思考字段，并移除旧的“测试模型”配置项。
- 修复“禁用冷却”和 Claude 用户 ID 缓存在选择关闭时未正确保存的问题；现在可明确选择使用默认值、启用或禁用。
- 修复内核 v8 配置中的空节点和新旧字段混用可能导致 TLS、敏感词等设置读取或写入异常的问题。
- 修正监听地址、使用统计、重试次数和重试间隔等设置未配置时的显示值，使其与内核实际行为一致。
- 修复 API 提供方编辑和模型选择弹窗在窄窗口或 macOS WebKit 下可能超出屏幕、无法正常滚动的问题。
