## 改善

- 最新版 ZCode の `.zcode/v2/provider_config.json` 設定形式に対応しました。他のプロバイダー設定を保持しながら、アプリからプロキシ接続とデフォルトモデルを設定・検出・復元できます。
- 「バージョン管理」画面に入るたびに、アプリとコアの更新を自動確認するようにしました。画面に戻ると再確認できます。
- プロバイダーの優先度に負の整数を指定できるようにし、保存前に入力範囲を検証します。
- セッションアフィニティ TTL は保存前に期間の形式を検証し、`30m` や `1h30m` などの指定に対応します。空欄では既定値を使用し、1 秒未満の有効な値は 1 秒として保存します。
- コア v8 の管理 API でエラーが発生した際に、エラーの種類と詳細な理由を両方表示し、無効な設定を特定しやすくしました。

## 修正

- macOS の更新時に DMG が一時的に使用中でアンマウントに失敗すると、更新が中断する場合がある問題を修正しました。アンマウントを再試行し、必要に応じてクリーンアップを後回しにします。
- コア v8 のプロバイダーのグループ名とメモが読み込みまたは保存後に失われる場合がある問題を修正しました。重複判定はグループ名に左右されなくなりました。
- グループ名が誤ったフィールドに書き込まれ、DeepSeek の認証情報の保存がコア側で拒否される問題を修正しました。
- プロバイダーの編集時にモデルの推論設定が上書きされる場合がある問題を修正しました。推論レベルを変更していない場合は各モデルの既存設定を保持し、手動で消去した場合は古い値を復元しません。
- モデル検出結果の推論フィールドに対応し、旧「テストモデル」設定項目を削除しました。
- 「クールダウンを無効化」と Claude ユーザー ID キャッシュをオフにした際、その選択が正しく保存されない問題を修正しました。既定値、有効、無効を明示的に選べます。
- コア v8 の設定にある空のノードや新旧フィールドの混在によって、TLS やセンシティブワードなどの設定の読み書きが正しく行われない場合がある問題を修正しました。
- 待ち受けアドレス、使用統計、再試行回数、再試行間隔が未設定の場合の表示を、コアの実際の動作に合わせて修正しました。
- API プロバイダーの編集ダイアログとモデル選択ダイアログが、狭いウィンドウや macOS WebKit で画面外にはみ出し、正常にスクロールできない問題を修正しました。
