## 追加

- **コアを停止せずに ECPA を更新**：Windows と macOS では、アプリの更新確認画面で「コアも再起動する」のチェックを外すと、現在のコアとコアに直接接続する Agent の実行を維持できます。既定では引き続きコアを再起動します。ECPA のみを更新した場合、新しく同梱されたコアの適用は保留され、後から手動で更新できます。ECPA が提供するプロキシ接続と管理対象の DeepSeek Harness は、GUI の再起動時に停止します。Linux では現在、コアの再起動が必要です。

## 改善

- **プラグインページのレイアウト**：サブページのタブを他のページと共通のスタイルに統一し、ウィンドウ幅が狭い場合のローカルプラグインとストアの検索欄・操作ボタンの配置を調整しました。
- **モデルカタログの読み込み**：ZCode のモデルエディターを開く際や設定を生成する際、外部のモデル能力カタログを一度だけ読み込むようにし、モデルごとの重複読み込みをなくしました。

## 修正

- **ZCode の設定時に発生する過剰なディスク読み込み**：リクエスト履歴に基づくモデル能力の自動補正を削除しました。モデルエディターを開く際や設定を生成する際に、モデルごとに過去の使用量記録を繰り返し走査しなくなりました。モデルの既定値、外部カタログの情報、手動設定は引き続き利用できます。
- **保存済みの ZCode 設定が既定値で上書きされる問題**：明示的に保存したコンテキストサイズと空の推論レベル選択を保持し、推定した既定値で置き換えないようにしました。
