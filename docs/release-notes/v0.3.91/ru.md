## Добавлено

- **Обновление ECPA без перезапуска ядра**: в Windows и macOS теперь можно снять флажок «Также перезапустить ядро» при подтверждении обновления приложения, чтобы текущее ядро и подключённые к нему напрямую агенты продолжали работать. По умолчанию ядро по-прежнему перезапускается. При обновлении только ECPA установка нового ядра из комплекта откладывается до ручного обновления. Прокси-соединения, обслуживаемые ECPA, и управляемый DeepSeek Harness всё равно останавливаются при перезапуске интерфейса. В Linux перезапуск ядра пока обязателен.

## Улучшено

- **Компоновка страницы плагинов**: стиль вкладок приведён к общему виду с другими страницами. В узких окнах выровнено расположение поля поиска и кнопок действий для локальных плагинов и магазина.
- **Загрузка каталога моделей**: при открытии редактора моделей ZCode или формировании конфигурации внешний каталог возможностей моделей загружается один раз, а не заново для каждой модели.

## Исправлено

- **Чрезмерное чтение с диска при настройке ZCode**: удалена автоматическая калибровка возможностей моделей по истории запросов. При открытии редактора моделей или формировании конфигурации больше не выполняется повторное сканирование истории использования для каждой модели. Значения по умолчанию, данные внешнего каталога и ручные настройки сохранены.
- **Замена сохранённых настроек ZCode значениями по умолчанию**: явно сохранённый размер контекстного окна и пустой список уровней рассуждения теперь сохраняются, а не заменяются вычисленными значениями по умолчанию.
