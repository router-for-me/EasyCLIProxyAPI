## 新增

- **更新 ECPA 時可保持核心執行**：Windows 和 macOS 使用者可在軟體更新確認視窗中取消勾選「同時重新啟動核心」，讓目前的核心及直接連線至核心的 Agent 保持執行。預設仍會重新啟動核心；選擇僅更新 ECPA 後，新版隨附的核心暫不啟用，之後可手動更新。由 ECPA 承載的代理連線和託管的 DeepSeek Harness 仍會隨介面重新啟動而停止；Linux 目前仍須重新啟動核心。

## 最佳化

- **外掛頁面版面配置**：統一外掛子頁面與其他頁面的分頁樣式，調整窄視窗下本機外掛和商店的搜尋框及操作按鈕排列。
- **模型目錄讀取**：ZCode 開啟模型編輯器或產生設定時，外部模型能力目錄只載入一次，避免逐一為每個模型重複讀取。

## 修復

- **ZCode 設定導致磁碟讀取過高**：移除根據歷史請求自動校準模型能力的邏輯，開啟模型編輯器或產生設定時，不再為每個模型反覆掃描歷史用量紀錄。保留模型預設值、外部目錄資訊和手動設定。
- **ZCode 已儲存設定被預設值覆蓋**：保留明確儲存的上下文大小及空白的推理等級選項，避免被推斷出的預設值取代。
