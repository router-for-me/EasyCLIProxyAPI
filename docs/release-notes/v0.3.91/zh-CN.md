## 新增

- **更新 ECPA 时可保持内核运行**：Windows 和 macOS 用户可在软件升级确认框中取消勾选「同时重启内核」，使当前内核及直接连接内核的 Agent 保持运行。默认仍会重启内核；选择仅更新 ECPA 后，新版附带内核暂不启用，后续可手动更新。由 ECPA 承载的代理连接和托管的 DeepSeek Harness 仍会随界面重启而停止；Linux 暂需重启内核。

## 优化

- **插件页面布局**：统一插件子页面与其他页面的标签样式，调整窄窗口下本地插件和商店的搜索框及操作按钮排列。
- **模型目录读取**：ZCode 打开模型编辑器或生成配置时，外部模型能力目录只加载一次，避免逐个模型重复读取。

## 修复

- **ZCode 配置导致磁盘读取过高**：移除根据历史请求自动校准模型能力的逻辑，打开模型编辑器或生成配置时，不再为每个模型反复扫描历史用量记录。保留模型默认值、外部目录信息和手动设置。
- **ZCode 已保存设置被默认值覆盖**：保留明确保存的上下文大小及空推理等级选项，避免被推断出的默认值替换。
