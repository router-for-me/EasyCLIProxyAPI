## 新增

- 版本管理页新增软件更新说明，可直接查看最新版的更新内容和发布日期。
- 更新说明支持简体中文、繁体中文、英文和日文，随界面语言切换，支持展开、收起和查看完整发布说明。当前语言的内容暂缺时直接显示提示，不切换到其他语言。

## 优化

- 优化使用记录页请求明细的横向滚动，修复快速拖动时响应滞后、内容回跳的问题；调整窗口大小、列宽或显示列时，滚动位置和范围保持同步。
- 更新日志设置说明，提示错误请求的记录范围，并提醒及时关闭“写入日志文件”，避免占用过多存储空间。

## 修复

- 修复同密钥、同基础地址但模型映射或优先级不同的 Claude、Codex 接入条目无法保存的问题。完全相同的配置仍会提示重复。([#276](https://github.com/router-for-me/EasyCLIProxyAPI/issues/276))
- 修复共享密钥条目在编辑、启停、排序、删除及备注管理时可能相互影响的问题，保留并迁移已有备注，避免误改或误删其他条目。
- 改进智能体解除接入时的配置恢复，保留用户在接入后自行修改的设置；保留 Claude Code 自定义子智能体模型和 Claude Desktop 的 Cowork 网络访问设置。
- 修复 Codex 恢复原生配置或解除接入时移除提供商配置的问题，保留历史会话所需的配置。
