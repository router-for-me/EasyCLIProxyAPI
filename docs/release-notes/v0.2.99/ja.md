## 新機能

- バージョン管理ページに更新内容を追加しました。最新版の変更点と公開日を確認できます。
- 更新内容は簡体字中国語、繁体字中国語、英語、日本語に対応し、画面の言語に合わせて表示されます。展開・折りたたみとリリースページへのリンクに対応します。選択した言語の内容がない場合は、別の言語に切り替えず案内を表示します。

## 改善

- 使用記録ページのリクエスト詳細で横スクロールを改善し、素早くドラッグした際の反応の遅れや表示位置が戻る問題を修正しました。ウィンドウサイズ、列幅、表示する列を変更した際も、スクロール位置と範囲を同期します。
- ログ設定の説明を更新し、記録対象となるエラーリクエストの範囲と、ストレージの過剰な使用を避けるために不要になったら「ログファイルへ書き込む」を無効にすることを案内します。

## 修正

- API キーとベース URL が同じでも、モデルのマッピングや優先度が異なる Claude・Codex の接続設定を保存できるようにしました。完全に同じ設定は引き続き重複として扱います。([#276](https://github.com/router-for-me/EasyCLIProxyAPI/issues/276))
- 同じ API キーを使用する接続の編集、有効・無効の切り替え、並べ替え、削除、メモ管理が他の接続に影響する問題を修正しました。既存のメモを保持して移行し、選択した接続だけを操作します。
- エージェント連携解除時の設定復元を改善し、連携後にユーザーが変更した設定を保持します。Claude Code のカスタムサブエージェントモデルと Claude Desktop の Cowork ネットワークアクセス設定も保持します。
- Codex の元の設定への復元や連携解除時にプロバイダー設定が削除される問題を修正し、過去のセッションに必要な設定を保持します。
