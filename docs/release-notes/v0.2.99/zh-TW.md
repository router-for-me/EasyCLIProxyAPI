## 新增

- 版本管理頁新增軟體更新說明，可直接查看最新版的更新內容和發布日期。
- 更新說明支援簡體中文、繁體中文、英文及日文，隨介面語言切換，支援展開、收合及查看完整發布說明。缺少目前語言的內容時會直接顯示提示，不會切換至其他語言。

## 優化

- 改善使用記錄頁請求明細的水平捲動，修正快速拖曳時反應延遲、內容跳回的問題；調整視窗大小、欄寬或顯示欄位時，捲動位置與範圍保持同步。
- 更新日誌設定說明，提示錯誤請求的記錄範圍，並提醒及時關閉「寫入日誌檔案」，避免占用過多儲存空間。

## 修正

- 修正使用相同金鑰、相同基礎位址，但模型對應或優先順序不同的 Claude、Codex 連線項目無法儲存的問題。完全相同的設定仍會提示重複。([#276](https://github.com/router-for-me/EasyCLIProxyAPI/issues/276))
- 修正共用金鑰的項目在編輯、啟停、排序、刪除及備註管理時可能互相影響的問題，保留並遷移既有備註，避免誤改或誤刪其他項目。
- 改善智慧代理解除連線時的設定還原，保留使用者在連線後自行修改的設定；保留 Claude Code 自訂子代理模型及 Claude Desktop 的 Cowork 網路存取設定。
- 修正 Codex 還原原生設定或解除連線時移除供應商設定的問題，保留歷史工作階段所需的設定。
