这个版本补齐插件 OAuth 登录的多入口体验：一个插件声明多个 OAuth 提供商时，登录面板现在会为每个提供商单独显示一张卡片，各自的名称和图标都取自插件自己的声明，多选门户也能逐项选择。

如果你在使用中遇到问题，请通过 [QQ群](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 反馈，我们会尽快处理。

## 新功能

- **插件 OAuth 多提供商独立成卡**：同一个插件提供多个 OAuth 登录入口时，每个提供商单独展示一张卡片，使用该插件声明的名称和图标，不再合并成一个入口。
- **登录门户支持逐项选择**：为插件配置登录门户时可以按提供商分别指定，不再只能对整份插件设置一个门户。
- **提供商发现更稳健**：只读取真正启用且声明了有效 OAuth 提供商的插件，按提供商去重并排除内置项，后端新增的提供商无需前端白名单即可显示。
