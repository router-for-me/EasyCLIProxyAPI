## 新增

- **模型目錄改為按需重新整理**：首頁新增重新整理按鈕，需要時手動拉取模型目錄，不再於背景週期性同步，減少無用請求與介面等待。

## 修正

- **Codex 目錄同步不再於背景自動執行**：背景目錄同步已移除，改由首頁手動重新整理觸發，避免在未察覺時改寫模型清單。
- **OpenAI 相容服務不再出現不支援的模型開關**：API 存取頁對不支援模型切換的相容服務隱藏了對應開關，避免設定無效狀態。
- **更新檢查與下載統一使用所選下載來源**：更新檢查與下載現在都走使用者選擇的來源，不再出現檢查用一個來源、下載用另一個來源的情況。
- **ZCode 儲存流程與 Codex 目錄一致**：ZCode 模型目錄的儲存與持久化行為與 Codex 保持一致，並新增 ultra 推理等級。

## 調整

- **認證檔案卡片操作區更精簡**：卡片上的操作保持簡潔，模型排除項目統一收攏到設定對話框中管理。
