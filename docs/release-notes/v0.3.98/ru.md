## Добавлено

- **Обновление каталога моделей по требованию**: на главной странице появилась кнопка обновления, поэтому каталог моделей загружается по запросу, а не синхронизируется периодически в фоне. Меньше лишних запросов и ожидания в интерфейсе.

## Исправлено

- **Синхронизация каталога Codex больше не выполняется в фоне**: фоновая синхронизация удалена, она запускается ручным обновлением на главной странице, поэтому список моделей не переписывается незаметно.
- **Неподдерживаемые переключатели моделей у OpenAI-совместимых провайдеров больше не появляются**: на странице доступа к API переключатель скрыт для провайдеров, которые его не поддерживают.
- **Проверка и загрузка обновлений используют выбранный источник**: обе операции следуют выбранному источнику загрузки, больше не бывает разных источников для проверки и загрузки.
- **Сохранение ZCode соответствует каталогу Codex**: поведение сохранения и хранения каталога моделей ZCode теперь совпадает с Codex, добавлен уровень рассуждений ultra.

## Изменено

- **Более аккуратные действия в карточке файлов авторизации**: действия на карточке остаются компактными, а исключения моделей управляются в диалоге настроек.
