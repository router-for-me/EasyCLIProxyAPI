## 追加

- **モデルカタログのオンデマンド更新**：ホームページに更新ボタンを追加し、必要なときだけモデルカタログを取得するようになりました。バックグラウンドでの定期同期は行われないため、無駄なリクエストと待ち時間が減ります。

## 修正

- **Codex のカタログ同期がバックグラウンドで動かなくなりました**：バックグラウンド同期を廃止し、ホームページの手動更新で実行するようにしました。気づかないうちにモデル一覧が書き換わることはありません。
- **OpenAI 互換プロバイダーで非対応のモデル切り替えが表示されなくなりました**：モデル切り替えに対応していないプロバイダーでは、API アクセスページで該当するスイッチを非表示にしました。
- **アップデート確認とダウンロードが選択した取得元を統一して使うようになりました**：確認とダウンロードの両方が選択した取得元を使うため、別々の取得元が使われることはありません。
- **ZCode の保存フローを Codex のカタログに合わせました**：ZCode モデルカタログの保存と永続化が Codex と同じ挙動になり、ultra 推論レベルを追加しました。

## 変更

- **認証ファイルカードの操作を整理しました**：カード上の操作を簡潔に保ち、モデル除外の管理は設定ダイアログに集約しました。
