## 不具合修正

- Linux での再起動操作によるウィンドウ表示とサイレント起動の改善：Linux でアプリがバックグラウンドまたはシステムトレイで動作している際に、ランチャーやデスクトップショートカットを再度クリックしても反応しない問題を修正しました。インスタンスロックを保持するプロセスがローカルの Unix ソケットでアクティベーション要求を待ち受け、後続の起動操作で実行中のインスタンスにメインウィンドウの表示・復元・最前面への移動を要求します。Linux のサイレント起動はログイン時の自動起動（`--autostart` 引数、gnome-session の `DESKTOP_AUTOSTART_ID` の検出、または systemd の自動起動サービス）にのみ適用されるようになりました。アプリケーションメニューやショートカットから手動で起動した場合はメインウィンドウを通常どおり表示し、システムトレイのない環境や Waybar を使用する一部のデスクトップ環境でウィンドウを再表示できない問題を解消しました（[#550](https://github.com/router-for-me/EasyCLIProxyAPI/pull/550)）。
