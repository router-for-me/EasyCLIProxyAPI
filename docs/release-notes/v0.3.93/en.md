## Improved

- **Output speed now defaults to total request latency**: the Usage records and Overview TPS figures are calculated over the whole request by default, including the wait for the first token, so the number matches what a request feels like end to end. To read the model's own writing speed instead, switch back to "after the first token" in Usage records → display settings; the choice is remembered.
