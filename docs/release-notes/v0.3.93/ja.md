## 改善

- **出力速度の既定値をリクエスト全体の所要時間に変更**：使用記録と概要ページの TPS は、既定で「全体の所要時間」を基準に計算するようになりました。最初のトークンを待つ時間も含むため、リクエストを投げてから受け取り終えるまでの体感速度に近づきます。モデル自体の生成速度を見たい場合は、「使用記録 → 表示設定」で「最初のトークン以降の区間」に切り替えられます。選択内容は保存されます。
