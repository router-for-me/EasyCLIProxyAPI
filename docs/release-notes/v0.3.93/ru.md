## Улучшено

- **Скорость вывода по умолчанию считается по полному времени запроса**: показатели TPS в истории использования и на странице обзора теперь по умолчанию учитывают всё время запроса, включая ожидание первого токена, поэтому число ближе к тому, что пользователь ощущает от запроса целиком. Если нужна скорость самой генерации модели, переключитесь на «после первого токена» в разделе «История использования → настройки отображения»; выбор запоминается.
