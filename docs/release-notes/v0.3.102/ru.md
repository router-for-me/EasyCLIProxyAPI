## Исправлено

- **Поиск Codex CLI**: Codex CLI теперь также находит исполняемые файлы, встроенные в настольное приложение, включая пакеты из Windows Store/MSIX, отдельные ресурсы настольной версии для Windows и пакеты приложения macOS.
- **Выбор Codex CLI**: Кандидаты теперь сравниваются по семантической версии, а не берётся первый рабочий вариант, поэтому устаревший перемещённый кэш больше не выбирается. При одинаковых версиях приоритет отдаётся отдельному CLI из каталогов поиска, затем встроенной версии настольного приложения, затем старому кэшу.
- **Порядок стабильных и предварительных версий**: Стабильная версия превосходит предварительную только при одинаковой базовой версии, поэтому предварительная версия с более новой базовой версией по-прежнему превосходит более старую стабильную.
