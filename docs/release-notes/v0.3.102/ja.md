## 修正

- **Codex CLI の検出**：デスクトップアプリに同梱された実行ファイルも検出できるようになりました。Windows ストア/MSIX でインストールされたパッケージ、Windows デスクトップ版の単体リソース、macOS のアプリバンドルが対象です。
- **Codex CLI の選択**：候補は最初に利用可能なものではなくセマンティックバージョンで比較されるようになり、古い再配置キャッシュが選ばれなくなりました。バージョンが同じ場合は、検索ディレクトリの単体 CLI、デスクトップアプリ同梱版、旧キャッシュの順に優先されます。
- **正式版とプレリリースの順序**：正式版がプレリリースより優先されるのは同じコアバージョンの場合のみで、コアバージョンが新しいプレリリースは古い正式版より優先されます。
