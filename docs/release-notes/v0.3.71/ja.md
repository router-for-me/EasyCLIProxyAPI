## 追加

- **カードレイアウトの切り替え（クォータ照会 / 認証ファイル）**: 両ページの右上に「カードレイアウト」スイッチを追加し、3 種類の並べ方を切り替えられるようになりました。選択内容はページごとに保存されます。
  - **等高行**（既定）: 同じ行のカードの高さが揃い、下部の操作ボタンが一直線に並びます。
  - **スタック**: カードを列ごとに詰めて並べるため、背の低いカードの下に余白が残りません。
  - **コンパクト**: 1 行に 1 枚の小さなカードで、アカウントが多いときに一覧しやすくなります。クォータ照会では名前・プラン・各上限のバー、認証ファイルでは名前・状態・プラン・残量が最も少ないクォータを表示し、矢印ボタンで元のカードに展開できます。
- レイアウトスイッチはキーボードで操作でき、コンパクトカードの展開・折りたたみもキーボードで行えます。新しい文言は英語・簡体字中国語・日本語・繁体字中国語に追加しました。

## 変更

- **クォータ照会の既定レイアウトを変更**: 既定が「カードを上寄せ」から「等高行」になり、照会に失敗したカードなどの低いカードは同じ行の高さまで引き伸ばされます。認証ファイルページの見た目は従来どおりです。
