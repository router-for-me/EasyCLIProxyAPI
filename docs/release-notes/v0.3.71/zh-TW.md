## 新增

- **卡片版面切換（額度查詢 / 認證檔案）**：這兩個頁面右上角新增「卡片版面」開關，可在三種排列之間切換，每個頁面各自記住自己的選擇。
  - **等高列**（預設）：同一列內卡片高度一致，底部操作按鈕對齊。
  - **堆疊**：卡片依欄緊密排列，短卡片下方不再留下空白列。
  - **緊湊**：一列一張小卡片，適合帳號較多時快速掃視；額度查詢頁顯示名稱、方案與每條限額的進度條，認證檔案頁顯示名稱、狀態、方案與最低剩餘額度，點擊箭頭可展開完整卡片。
- 版面開關支援鍵盤操作，緊湊卡片的展開與收合同樣可用鍵盤完成；相關文案已補齊英文、簡體中文、日文與繁體中文。

## 調整

- **額度查詢頁預設排列變更**：預設版面由原本的「卡片貼頂」改為「等高列」，較短的狀態卡片會被拉高到與同列卡片等高，掃視時更整齊。認證檔案頁的外觀與之前保持一致。
