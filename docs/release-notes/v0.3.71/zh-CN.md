## 新增

- **卡片布局切换（额度查询 / 认证文件）**：这两个页面右上角新增「卡片布局」开关，可在三种排布间切换，每个页面各自记住自己的选择。
  - **等高行**（默认）：同一行内卡片高度一致，底部操作按钮对齐。
  - **堆叠**：卡片按列紧密排列，短卡片下方不再留空行。
  - **紧凑**：一行一张小卡片，适合账号较多时快速扫视；额度查询页显示名称、套餐与每条限额的进度条，认证文件页显示名称、状态、套餐和最低剩余额度，点击箭头可展开完整卡片。
- 布局开关支持键盘操作，紧凑卡片的展开/收起同样可用键盘完成；相关文案已补齐英文、简体中文、日文与繁体中文。

## 调整

- **额度查询页默认排布变化**：默认布局由原来的「卡片贴顶」改为「等高行」，较短的状态卡片会被拉伸到与同排卡片等高，扫视时更整齐。认证文件页的外观与之前保持一致。
