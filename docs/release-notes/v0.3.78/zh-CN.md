这个版本让插件中心开箱可用，修好了从插件商店安装插件、以及在正式版里切换更新通道后拿不到升级的问题；同时把内置内核升级到最新版本，并在下载包时正确走你选择的镜像源。

如果你在使用中遇到问题，请通过 [QQ群](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 反馈，我们会尽快处理。

## 新功能

- **ECPA 精选插件开箱可装**：进入插件页会自动注册 ECPA 插件源，不用再手动点按钮，也不再常驻"已注册为插件源"的提示横幅。精选页的加载状态、空状态和错误提示都重做过，源不可用时会直接说明原因，而不是只留一句"插件不存在"。
- **插件商店支持通过已注册源安装**：精选插件现在走统一的安装流程，能显示安装进度、失败原因和已安装状态。
- **模型别名支持创建表单**：可以在界面上直接创建模型别名，选原模型、选加速档位后自动生成别名，不用手写配置。
- **额度账号备注**：额度列表可以给账号加备注，编辑器改成行内下划线输入，添加和清除都在原位置完成，不再弹一层对话框。
- **Codex 模型可见性批量控制**：可以一次勾选多个模型启用或隐藏，配额页也提供了紧凑视图。

## 修复

- **切换更新通道后没有「立即升级」**：带时间戳的构建版本号形如 `0.3.6-preview.20261106-1137`，按语义化版本规则永远低于 `0.3.6`，所以从正式版切到其他更新通道时，更新检查判定"没有新版本"，只剩一个下载按钮。现在这类构建会被正确识别为新版本，切换通道后即可直接应用内升级。
- **手动下载忽略了所选下载源**：桌面客户端的下载按钮直接用清单里的 GitHub 原始地址打开浏览器，选中的镜像源只用于拉取版本清单，真正下载包时没有生效。现在下载链接会按当前下载源套用镜像前缀。
- **插件中心没有设置入口**：GitHub Token 以前要填在插件页的折叠面板里，现在改为页面内的轻量文字链接，点击直接跳到「设置 → 服务器 → GitHub Token」，限流提示里也会带上这个入口。
- **插件卡片的打开链接按钮太小**：原来是个很小的图标按钮，现在改成带文字的常规按钮，点击区域不小于 32px。
- **路由编排的确认弹窗样式不统一**：应用改动的确认框原来是一张串行表单，现在改成和关闭窗口确认框一致的样式，改动项列表有边框、行对齐，取消和确认都在固定位置。
- **使用记录的图表留白**：宽标签（例如带货币符号的刻度）会被图表边缘裁掉，现在图表侧边距按当前语言的实际刻度宽度计算。
- **ZCode 预设参数报错**：`maxOutputTokens` 里带了一个无效的 map 字段，导致该 provider 的配置校验失败，已移除。

## 优化

- **内置内核升级到 8.0.58**：发布包携带的内核更新到最新版本，首次启动即可用上新内核。
- **DeepSeek Harness 默认敏感词**：Devin 默认敏感词里补上了 DeepSeek Harness。
