## 追加

- **プラグイン更新のお知らせ**：起動後にインストール済みプラグインの新しいバージョンをバックグラウンドで確認し、更新がある場合はサイドバーの「プラグイン」項目にバージョン管理と同じ黄色のランプを表示します。確認は自動インストールを行わず、プラグインページで個別またはまとめて更新する必要があります。取得元がオフラインのときは何も表示せず、見つかった更新はインストールまたはアンインストールまで保持されます。

## 改善

- **プラグインページのレイアウト**：ローカルプラグインとストアのツールバーをグループ化し、狭いウィンドウでは検索欄と操作ボタンが折り返して並ぶようにしました。カードの幅を広げ、カード内のタイトル・識別子・メタ情報のスタイルを統一しました。
- **タグ選択**：プラグインページのタグ絞り込みで、よく使うタグと選択ボタンを分けて表示し、選択ボタンには選択数とタグ名のみを表示するようにしました。長いタグはマウスオーバーで全体を確認できます。

## 修正

- **Gemini のクォータグループ**：Gemini モデルのグループでモデル名を個別に列挙せず、グループの概要を表示するようにしました。
- **Claude Desktop の行ごとの 1M コンテキスト設定が消える問題**：他の設定を変更したり設定を再読み込みしたりしても、保存済みの各行の 1M コンテキストのチェック状態を保持し、リセットされないようにしました。
