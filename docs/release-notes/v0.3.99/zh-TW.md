## 新增

- **外掛更新提示**：啟動後會在背景檢查已安裝的外掛是否有新版本，有更新時在側邊欄「外掛」項目顯示與版本管理相同的黃色提示燈。檢查不會自動安裝，仍須在外掛頁面逐一或全部更新。來源離線時保持靜默，已知的更新在安裝或解除安裝前會一直保留。

## 最佳化

- **外掛頁面版面配置**：調整本機外掛和商店的工具列分組，搜尋框與操作按鈕在窄視窗下換行排列，外掛卡片加寬並統一了卡片內標題、識別碼與中繼資料的樣式。
- **標籤選擇**：外掛頁的標籤篩選將常用標籤與選擇器分開顯示，選擇器只顯示已選數量和標籤名稱，長標籤可懸停查看完整內容。

## 修復

- **Gemini 配額分組**：Gemini 模型分組不再逐一列出模型名稱，改為顯示分組摘要。
- **Claude Desktop 逐列 1M 上下文設定被清除**：修改其他設定或重新載入設定時，保留已儲存的每一列模型的 1M 上下文勾選狀態，不再被重設。
