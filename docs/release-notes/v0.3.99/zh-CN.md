## 新增

- **插件更新提示**：启动后会在后台检查已安装的插件是否有新版本，有更新时在侧边栏「插件」入口显示与版本管理相同的黄色提示灯。检查不会自动安装，仍需在插件页面逐个或全部更新。来源离线时保持静默，已知的更新在安装或卸载前会一直保留。

## 优化

- **插件页面布局**：调整本地插件和商店的工具栏分组，搜索框与操作按钮在窄窗口下换行排列，插件卡片加宽并统一了卡片内标题、标识与元信息的样式。
- **标签选择**：插件页的标签筛选把常用标签与选择器分开显示，选择器只显示已选数量和标签名称，长标签可悬停查看完整内容。

## 修复

- **Gemini 配额分组**：Gemini 模型分组不再逐个列出模型名称，改为显示分组摘要。
- **Claude Desktop 逐行 1M 上下文设置被清除**：修改其他设置或重新加载配置时，保留已保存的每一行模型的 1M 上下文勾选状态，不再被重置。
