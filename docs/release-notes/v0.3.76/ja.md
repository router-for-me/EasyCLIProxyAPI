## 修正

- **環境ディレクトリが多い環境でエージェント検出が CPU を消費する**：起動時とエージェント検出時に `.local/state/fnm_multishells` と `.nvm/versions/node` 配下のディレクトリをすべて走査しますが、新しいパスを追加するたびに、すでに収集した全パスと突き合わせていました。FNM ディレクトリが大量に溜まっている環境（約 199,000 件という報告があります）では比較回数が二乗で増え、モデルへのリクエストがなくても CPU を使い続けていました（実測 57%〜62%）。現在はハッシュ集合で重複判定し、元のパス順序と最初に現れた表記をそのまま保ちます。

## 改善

- **重複除去の結果は従来と完全に同一**：重複、末尾スラッシュ、`/./` の違いだけの等価パス、空のエントリはいずれも以前と同じ動作で、実行ファイル検索の優先順位には影響しません。
