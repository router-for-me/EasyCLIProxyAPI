## 新增

- **导入自定义主题**：可以在主题选择器中直接选择 ZIP 压缩包或主题文件夹。替换已有主题文件夹前会要求确认。
- **编辑受支持智能体的系统提示词**：ZCode 等受支持的智能体可自定义默认提示词，也可按模型单独覆盖。内核启用 TLS 时会阻止提示词改写，避免连接降级到明文 HTTP；已设置的覆盖仍可清除。
- **Antigravity 停用处理设置**：桌面应用内置 8.0.78 内核，可设置因违反服务条款而被停用时的保护性暂停时长。对于当前停用的凭据，如有申诉链接，界面会显示入口。

## 改进

- **自动更新移入「桌面应用」卡片**：关闭时收起应用与内核两个更新对象，开启后才显示。下方简短说明后台下载和下次启动时安装的行为。即使应用不支持自动更新，也可单独配置内核更新。启动时的行为没有改变。
- **补看跳过版本的更新说明**：检查稳定版更新时，应用会在最新版说明后列出可用的中间版本说明。
- **更清楚地查看请求来源和去向**：实时路由按客户端、模型和凭据归纳已记录的路径，可固定近期已完成的请求查看详情。会话粘性还新增「从不重绑」选项，让已建立的会话保留原凭据。
- **查看和编辑模型价格更方便**：可搜索的卡片区分手动定价、同步定价和未定价的模型，并显示有价格覆盖的请求数。可在侧栏编辑每百万 Token 的费率，同步时也可选择要更新的模型。
- **说明智能体为何无法接入**：接入操作不可用时，会提示模型映射不完整、平台不受支持等原因。

## 修复

- **重启后保留凭据停用历史**：可区分 Antigravity 凭据当前停用和历史停用，较长的说明会收在详情里，不再挤占状态标签。
