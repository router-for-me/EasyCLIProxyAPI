## 新增

- **匯入自訂主題**：可以在主題選擇器中直接選擇 ZIP 壓縮檔或主題資料夾。取代現有的主題資料夾前會要求確認。
- **編輯受支援代理的系統提示詞**：ZCode 等受支援的代理可自訂預設提示詞，也可依模型個別覆寫。核心啟用 TLS 時會阻擋提示詞改寫，避免連線降級為明文 HTTP；已設定的覆寫仍可清除。
- **Antigravity 停權處理設定**：桌面應用程式內建 8.0.78 核心，可設定因違反服務條款而停權時的保護性暫停時間。憑證目前停權且有申訴連結時，介面會顯示申訴入口。

## 改進

- **自動更新移入「桌面應用程式」卡片**：關閉時收合應用程式與核心兩個更新對象，開啟後才顯示。下方簡短說明背景下載和下次啟動時安裝的行為。即使應用程式不支援自動更新，仍可單獨設定核心更新。啟動時的行為沒有改變。
- **補看略過版本的更新說明**：檢查穩定版更新時，應用程式會在最新版說明後列出可用的中間版本說明。
- **更清楚掌握請求的來源與去向**：即時路由依用戶端、模型和憑證分組顯示已記錄的路徑，也能釘選近期已完成的請求來查看詳細資訊。工作階段黏著另有「永不重新綁定」選項，讓已建立的工作階段留在原本的憑證。
- **更容易查看與編輯模型價格**：可搜尋的卡片會區分手動定價、同步定價和未定價的模型，並顯示多少請求有對應價格。可在側邊面板編輯每百萬 Token 的費率，同步時也可選擇要更新的模型。
- **說明代理無法連線的原因**：連線操作無法使用時，會提示模型對應不完整、平台不受支援等原因。

## 修復

- **重新啟動後保留憑證停權紀錄**：可區分 Antigravity 憑證目前停權與曾經停權，較長的說明會放在詳細資訊中，不再擠占狀態標籤。
