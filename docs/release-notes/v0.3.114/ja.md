## 追加

- **カスタムテーマのインポート**：テーマ選択画面から ZIP ファイルまたはテーマフォルダーを選べるようになりました。既存のテーマフォルダーを置き換える場合は確認が表示されます。
- **対応エージェントのシステムプロンプトを編集**：ZCode などの対応エージェントで、既定のプロンプトやモデル別の上書きを設定できます。コアで TLS が有効な場合は、接続を平文 HTTP に切り替えないようプロンプトの書き換えをブロックします。既存の上書き設定は解除できます。
- **Antigravity の利用停止設定**：コア 8.0.78 を同梱し、利用規約違反による利用停止時の保護用一時停止期間を設定できるようになりました。現在の利用停止に異議申し立て用のリンクがある場合は、そのリンクを表示します。

## 改善

- **自動更新を「デスクトップアプリ」のカードに移動**：アプリとコアの更新対象はスイッチをオンにすると表示されます。バックグラウンドでのダウンロードと次回起動時のインストールについても短い説明を表示します。アプリの自動更新が利用できない場合でも、コアの更新は設定できます。起動時の動作に変更はありません。
- **飛ばしたバージョンの更新内容を確認**：安定版の更新を確認すると、最新版の更新内容とあわせて、途中のバージョンについても入手可能な更新内容を表示します。
- **リクエストの送信元と経路がわかりやすく**：ライブ ルーティングでは、記録された経路をクライアント、モデル、認証情報ごとにグループ化し、最近完了したリクエストを固定して詳細を確認できます。セッション固定には、確立済みのセッションを元の認証情報に留める「再バインドしない」オプションも追加しました。
- **モデル料金の確認と編集が簡単に**：検索できるカードに手動設定・同期済み・未設定の料金と、料金設定が適用されるリクエスト数を表示します。サイドパネルで 100 万トークンあたりの料金を編集でき、同期時には更新するモデルを選べます。
- **エージェントを接続できない理由を表示**：モデルの割り当てが不足している、またはプラットフォームに対応していないなど、接続操作が無効になっている理由がわかります。

## 修正

- **認証情報の利用停止履歴を再起動後も保持**：Antigravity の過去の利用停止と現在の利用停止を区別できるようになりました。長い説明はステータスバッジに詰め込まず、詳細に表示します。
