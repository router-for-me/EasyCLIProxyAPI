这个版本让 ECPA 精选插件页面变得可用起来：插件简介会跟着界面语言切换，已安装的插件能看到新版本并就地更新，页面还多了一个手动刷新按钮，内置目录也补上了 FreeTier 2API。另外修掉了使用记录里 TPS 平均值的两处算法偏差。

如果你在使用中遇到问题，请通过 [QQ群](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 反馈，我们会尽快处理。

## 新功能

- **精选插件支持就地更新**：已安装的精选插件在加载时会查询各自的 GitHub 最新版本。有新版本时，版本号显示为「当前 → 最新」，卡片上是醒目的「可更新」标记和一个「更新」按钮，点开即可下载安装，装完标记自动消失，不用重新进页面。没有新版本的插件仍显示「已安装」。
- **精选插件页新增手动刷新**：搜索框右侧多了一个「刷新」按钮，按下会绕过本地缓存重新拉取精选目录，同时刷新插件源列表。想立刻看到目录更新时不用再等缓存过期或重启应用。
- **插件简介跟随界面语言**：精选目录里的插件现在使用目录提供的本地化简介。简体中文界面显示中文简介，繁体中文回退到简体中文，其他语言使用目录里的默认简介。

## 修复

- **TPS 平均值不再被失败请求拉低**：使用记录的吞吐统计以前会把失败请求一起计入平均，现在只统计成功的请求。
- **TPS 改为按单次请求计算**：吞吐量现在用每次请求自身的输出 token 数与耗时计算，不再拿整段时间的总量去除，数值更贴近实际响应速度。

## 优化

- **内置精选目录补上 FreeTier 2API**：网络不可用时应用会回退到内置目录，现在这份内置数据里也包含 FreeTier 2API，不会再出现只剩一个插件的空荡页面。
