## 新增
- 关于软件，如果您有任何问题或建议，请通过群里或者 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 提交，我们会尽快处理。
- 新增 Vertex AI 凭证导入：在登录页面选择 Google 服务账号 JSON，可指定 GCP 区域；导入成功后显示项目、服务账号和凭证文件信息。
- Agent 配置管理支持手动选择可执行文件。自动检测失败时可指定路径，并用于后续检测和启动。
- 使用记录会为 `priority` 和 `fast` 请求显示 Fast 标记。

## 优化

- 首页改为更轻量的概览布局，将状态与概览信息放在更醒目的位置。
- 使用记录的显示设置新增错误详情换行选项；默认单行展示，也可展开查看完整内容，设置会保留。
- 改进 ZCode 配置更新与识别，兼容现有地址写法，并保留手动模型配置中的上下文窗口。
- 改进 Hermes 和 OpenClaw 配置兼容性：识别 Hermes v12 的 provider 配置，遵循 OpenClaw 的自定义配置路径，并保留已有模型元数据。
- 凭证用量明确标注为内核运行期间的统计，凭证启用状态和操作按钮更清晰；补齐部分界面文案翻译。
- 内置 CLIProxyAPI 内核更新至 **8.0.22**。
