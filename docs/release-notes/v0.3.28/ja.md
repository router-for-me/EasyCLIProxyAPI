## 追加

- ソフトウェアについてご質問やご提案がある場合は、コミュニティチャットまたは [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) からお知らせください。できるだけ早く対応します。
- Vertex AI の認証情報をインポートできるようになりました。ログイン画面で Google サービスアカウントの JSON を選択し、必要に応じて GCP リージョンを指定できます。インポート後はプロジェクト、サービスアカウント、認証情報ファイルを確認できます。
- Agent の設定管理画面で実行ファイルを手動選択できるようになりました。自動検出に失敗した場合、指定したパスを検出と起動に使用します。
- 使用記録で `priority` と `fast` のリクエストに Fast バッジを表示するようになりました。

## 改善

- ホーム画面を軽量な概要レイアウトに刷新し、状態と概要情報を見やすくしました。
- 使用記録の表示設定にエラー詳細の折り返しオプションを追加しました。初期状態では 1 行で表示し、必要に応じて全文を展開できます。設定は保存されます。
- ZCode の設定更新と検出を改善し、既存のベース URL 形式に対応しました。手動設定したモデルのコンテキストウィンドウも保持します。
- Hermes と OpenClaw の設定互換性を改善しました。Hermes v12 の provider 設定を認識し、OpenClaw のカスタム設定パスを使用するとともに、既存のモデルメタデータを保持します。
- 認証情報の使用量がコアの実行中に集計された値であることを明示し、有効状態と操作ボタンを分かりやすくしました。一部の未翻訳ラベルも修正しました。
- 同梱の CLIProxyAPI コアを **8.0.22** に更新しました。
