## 修正

- **請求明細欄位偏好**：在「用量 → 請求明細」中主動隱藏 Key 欄位後，切換分頁、離開頁面再返回或重新啟動應用程式都會保留此選擇。有效的已儲存選擇不再被重設為預設值，新安裝仍預設顯示 10 個欄位。
- **ZCode 提供者設定**：清除失效及重複的模型項目，同時保留已儲存的選擇與排序，避免無效的上下文或輸出限制、空白或重複的推理等級導致自訂提供者消失。
- **Codex 登入方式切換**：切換 API Key 與 OAuth 登入時保留所選設定檔的設定；關閉受管設定後還原原有設定檔及憑證儲存偏好。
