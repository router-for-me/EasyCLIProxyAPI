## 修正

- **リクエスト詳細の表示列**：「使用量 → リクエスト詳細」で Key 列を非表示にした設定が、タブの切り替え、別の画面からの復帰、アプリの再起動後も保持されます。有効な保存済みの選択がデフォルトに戻されることはなく、新規インストール時は引き続きデフォルトの 10 列を表示します。
- **ZCode のプロバイダー設定**：保存済みの選択と表示順を維持しながら、無効になったモデルや重複した項目を整理します。不正なコンテキスト・出力上限や空・重複した推論レベルによってカスタムプロバイダーが消える問題を修正しました。
- **Codex のログイン方式切り替え**：API キーと OAuth のログインを切り替えても、選択中のプロファイルの設定を維持します。管理対象の設定を解除すると、元のプロファイルと認証情報の保存先設定を復元します。
