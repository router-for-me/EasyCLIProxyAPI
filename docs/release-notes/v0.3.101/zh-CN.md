## 修复

- **请求明细列偏好**：在「用量 → 请求明细」中主动隐藏 Key 列后，切换标签页、离开页面再返回或重启应用都会保留该选择。有效的已保存选择不再被重置为默认值，新安装仍默认显示 10 列。
- **ZCode 提供商配置**：清理失效及重复的模型条目，同时保留已保存的选择和排序，避免无效的上下文或输出限制、空白或重复的推理级别导致自定义提供商消失。
- **Codex 登录方式切换**：切换 API Key 与 OAuth 登录时保留所选配置档案的设置；关闭托管配置后恢复原有配置档案及凭据存储偏好。
