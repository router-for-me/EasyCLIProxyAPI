## Melhorias

- Os modelos conectados ao ZCode pelo CPA agora ativam a entrada de imagem por padrão, gerando `inputFormat.supportsImage: true`, inclusive modelos sem metadados de visão. As configurações manuais existentes são preservadas.
- Os plugins agora vêm ativados por padrão em instalações novas e em configurações sem um valor explícito. Uma configuração de plugin desativada de forma explícita permanece desativada.
- Atualizadas as capturas de tela do README para mostrar a interface atual e as páginas de configuração dos clientes.

## Notas de uso

- Depois de atualizar, reaplique a configuração do ZCode e reinicie o ZCode para usar a entrada de imagem padrão.
- As configurações de entrada de imagem permitem que o cliente envie imagens; o suporte real à visão ainda depende do modelo selecionado e do serviço de origem.

## Correções

- Corrigida a inconsistência do estado padrão dos plugins entre a configuração gerada e a página de configurações.
