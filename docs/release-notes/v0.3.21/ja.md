## v0.3.20 リリースノート

## 新機能

- プラグイン管理とプラグインストアを追加しました。インストール、更新、バージョン選択、有効化・無効化、アンインストール、設定編集、およびプラグインが提供する OAuth 認証に対応します。
- Muse（Meta）の OAuth デバイス認証を追加しました。Windows での DeepSeek Harness Desktop の検出と起動にも対応しました。
- Codex モデルのシステムプロンプトをカスタマイズできるようになりました。保存時にモデルカタログへ同期され、モデルの既定値に戻すこともできます。
- モデルの一括ヘルスチェックを追加しました。リクエスト履歴には実際の応答モデルを表示し、要求したモデルと異なる場合に通知します。
- リクエスト単位の推定費用と CSV エクスポートを追加しました。推論レベルを既定で表示し、使用量の確認や問題の調査をしやすくしました。

## 改善

- 同梱の CLIProxyAPI コアを **8.0.13** に更新し、管理 API の呼び出しと設定編集を v8 に対応させました。
- ダッシュボード、使用量分析、主要な管理ページを刷新しました。ライトテーマ、ナビゲーション、表のスタイルを統一し、ダークモードのコントラストと狭いウィンドウでのレイアウトを改善しました。
- 認証情報の管理をコンパクトな一覧に変更しました。プラン、状態、リクエスト統計、クォータをまとめて表示し、ページ切り替え、有効化・無効化、詳細の展開に対応するとともに、クールダウンの残り時間表示とリセット操作を改善しました。
- リクエスト、OAuth、プラグイン、同時実行、プロバイダーの設定項目を拡充しました。検索、入力検証、競合の警告、既定値への復元、再起動の案内も改善しました。
- API 接続で v8 ネイティブのプロバイダーグループと、認証情報ごとの編集・削除・並べ替えに対応しました。モデルエイリアスは専用タブに移動しました。
- クライアント一覧に検索、ページ切り替え、表示設定の保存を追加しました。インストール先の検出範囲を広げ、インストール済みクライアントを優先して表示します。
- バージョン管理に「同梱コアのインストール」を追加し、アプリに同梱されたローカルのコアパッケージから直接インストールできるようにしました。

## 修正

- v7 および新旧の形式が混在する設定から v8 への移行を修正し、キー、プロバイダー、モデルエイリアス、カスタム項目などの保持を改善しました。外部からの更新で未保存の設定が上書きされる問題も修正しました。
- 異なるアカウントの同名の認証情報でクールダウン状態が混同される問題と、OAuth のモデル除外設定の更新が他のプロバイダーに影響する問題を修正しました。
- コンテキスト長が異なるリクエストをまとめて集計する際の費用計算を修正し、費用推定の対象範囲をわかりやすくしました。
- モデルエイリアスの参照元の検証と Codex モデル ID の不統一を修正しました。また、ポータブル版の再構築時にインストール済みプラグインと実行データを保持するようにしました。
