## Melhorias

- **Padrões do Tool Search**: modelos de terceiros e desconhecidos agora permitem Tool Search por padrão. Seu uso ainda depende de suporte tanto do modelo quanto do serviço de origem. As escolhas explícitas salvas para cada modelo têm prioridade, e os padrões oficiais dos modelos de referência permanecem inalterados.
