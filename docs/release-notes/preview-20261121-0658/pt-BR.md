## Correções

- O ACP agora usa o login do Google próprio da CLI para contas isoladas e lida com caminhos do Windows e com os atalhos de execução da CLI. Uma falha na verificação de recursos não deixa mais "Adicionar e entrar" desativado; você pode tentar de novo sem mexer nas contas salvas.
- O ACP agora diferencia uma tentativa de autorização expirada, uma resposta recusada e uma falha de rede, para você saber se deve recomeçar o login ou conferir a sua conexão.

Esta prévia foi empacotada só para Windows x64.
