## Выбор экземпляра CPA и история использования

- После проверки подключения к внешнему CPA переключитесь на него в боковой панели. Маршрутизацией, клиентскими ключами и расширенными настройками выбранного сервера можно управлять на привычных страницах. При ошибке подключения приложение не переключается на встроенный CPA.
- Статистика собирается только для выбранного экземпляра. История и тарифы каждого внешнего URL хранятся отдельно от данных встроенного CPA. Замена ключа управления не меняет доступную историю.

## Доступ к ACP через API

- Дополнительный нативный модуль позволяет продолжать запросы Responses и возвращать результаты клиентских инструментов в исходный сеанс ACP. Модуль нужно собрать из исходного кода и установить вручную: он не входит в пакеты приложения и не включён по умолчанию. Интеграция проверена на Linux x64.
- По умолчанию системные инструкции по-прежнему передаются через механизм дополнения инструкций CLI. При необходимости их можно передавать один раз как обычный контекст первого запроса. Пул учётных записей включается отдельно; продолжение сеанса использует исходную учётную запись.
