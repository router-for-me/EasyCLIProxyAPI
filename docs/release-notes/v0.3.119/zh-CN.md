## CPA 实例选择与用量记录

- 在侧栏切换到验证通过的外部 CPA 后，可继续使用原有管理页面。路由、客户端密钥和高级设置均作用于所选服务器；连接失败不会回退到内置 CPA。
- 只采集当前实例的用量。每个外部地址都有独立的历史记录和定价设置，与内置实例分开；轮换管理密钥后仍可查看原有记录。

## ACP API 接入

- 可选的原生中继支持在原 ACP 会话中续接 Responses 请求、接收客户端工具结果。中继需手动从源码构建并安装，桌面安装包不内置，也不默认启用；已在 Linux x64 验证集成链路。
- 系统指令仍默认通过 CLI 的追加模式传递；可显式改为仅在首轮作为普通上下文发送。账户池也需单独启用，续接请求始终使用原账户。
