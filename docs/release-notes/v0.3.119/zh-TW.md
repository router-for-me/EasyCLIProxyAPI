## CPA 執行個體選擇與用量紀錄

- 在側邊欄切換至通過驗證的外部 CPA 後，可繼續使用原有的管理頁面。路由、用戶端金鑰及進階設定均套用至所選伺服器；連線失敗時不會改用內建 CPA。
- 僅收集目前執行個體的用量。每個外部位址都有獨立的歷史紀錄與定價設定，與內建執行個體分開；更換管理金鑰不會遺失原有紀錄。

## ACP API 存取

- 選用的原生中繼可在原 ACP 工作階段中接續 Responses 請求，並接收用戶端工具結果。中繼須自行從原始碼建置並安裝，桌面安裝套件不內含，也不會預設啟用；已在 Linux x64 驗證整合流程。
- 系統指令預設仍透過 CLI 的附加模式傳遞；也可選擇僅在首輪作為一般上下文傳送。帳號集區需另行啟用，接續請求仍使用原帳號。
