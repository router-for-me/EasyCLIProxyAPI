## CPA インスタンスの切り替えと利用履歴

- サイドバーで接続を確認した外部 CPA に切り替えても、同じ管理画面を使えます。ルーティング、クライアントキー、詳細設定の変更先は選択中のサーバーです。接続に失敗しても内蔵 CPA に切り替わることはありません。
- 利用状況を収集するのは選択中のインスタンスのみです。外部 URL ごとに履歴と料金設定が分かれ、内蔵 CPA の記録とは混在しません。管理キーを更新しても履歴は引き継がれます。

## ACP API 接続

- オプションのネイティブ中継を使うと、元の ACP セッションで Responses の会話を継続し、クライアント側のツール実行結果を返せます。中継はソースから手動でビルド・インストールする必要があり、デスクトップ版には同梱されず、既定では無効です。Linux x64 で連携を検証しました。
- システム指示は従来どおり CLI の追記モードで渡します。任意設定により、最初のターンだけ通常のコンテキストとして送ることもできます。アカウントプールも任意設定で、会話の続きには元のアカウントを使用します。
