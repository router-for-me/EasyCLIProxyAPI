## v0.3.20 发布说明
- 最近当前项目在优化UI，如果您有相关的建议或意见，欢迎在群聊或Github提出。

## 新增

- 新增插件管理与插件商店，支持安装、更新、选择版本、启停、卸载和配置编辑，并接入插件提供的 OAuth 授权。
- 新增 Muse（Meta）OAuth 设备授权；支持在 Windows 上检测并启动 DeepSeek Harness Desktop。
- 支持自定义 Codex 模型的系统提示词，保存后同步到模型目录，并可恢复模型默认值。
- 新增批量模型健康检查；请求记录展示实际响应模型，并提示请求模型与响应模型不一致的情况。
- 请求记录新增单次请求费用估算和 CSV 导出，默认展示思考等级，方便核对用量与排查问题。

## 优化

- 内置 CLIProxyAPI 内核升级至 **8.0.13**，管理接口与配置编辑适配 v8。
- 重构首页、用量分析及主要管理页面，统一浅色主题、导航和表格样式，改善深色模式对比度与窄窗口布局。
- 凭证管理改为紧凑列表，集中展示套餐、状态、请求统计与配额，支持分页、启停和详情展开，并完善冷却倒计时与重置操作。
- 高级设置新增更多结构化配置项，覆盖请求、OAuth、插件、并发与服务商设置；完善搜索、校验、冲突提示、恢复默认值及重启提示。
- API 接入支持 v8 原生服务商分组和逐条凭证编辑、删除、排序，模型别名单独展示在标签页中。
- 客户端列表支持搜索、分页和显示偏好保存，扩展安装路径检测并优先展示已安装客户端。
- 版本管理提供“安装内置内核”，可直接使用随应用附带的本地内核包。

## 修复

- 修复 v7 到 v8 及混合格式配置的迁移问题，完善密钥、服务商、模型别名、自定义字段等配置的保留，并避免外部刷新覆盖未保存的设置草稿。
- 修复不同账号的同名凭证冷却状态混淆，以及 OAuth 模型排除设置更新时影响其他服务商的问题。
- 修复不同上下文长度请求混合统计时的费用汇总，改进费用估算覆盖范围的展示。
- 修复模型别名来源校验与 Codex 模型 ID 使用不一致的问题，并在重建便携版时保留已安装插件及运行数据。
