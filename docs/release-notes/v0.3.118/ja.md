## 追加

- サイドバーの CPA 選択メニューから外部の CLIProxyAPI v8 サーバーに接続し、専用の Remote ワークスペースでクライアント API キーを管理できます。HTTP、HTTPS、リバースプロキシのパス接頭辞に対応し、条件付き保存で同時編集の上書きを防ぎます。内蔵 CPA と Remote CPA の切り替えは、ECPA を完全に終了して再起動すると反映されます。

## 改善

- ACP アカウントのログインに分離された CLI プロファイルを使用し、他の保存済みアカウントを置き換えずに追加・再認証できるようになりました。手動の認証リンクにも対応しています。Windows の CLI 起動スクリプトとパスの互換性を改善し、機能確認に失敗しても再試行できます。認証のタイムアウト、応答の拒否、リンク未取得、ネットワーク障害を区別して表示します。
- Stable と Preview のバージョンを個別に比較します。デスクトップのロゴをクリックすると、インストール済みアプリやバックグラウンド更新チャンネルを変更せずに、バージョン管理画面の参照系列を切り替えられます。自動更新は現在のアプリと同じリリース系列に限定されます。
- プロバイダーのモデル選択で件数を正しく表示し、上流の一覧に含まれない設定済みモデルも明示して保持します。
- 認証情報カードではよく使う操作を表示したまま、その他の操作をキーボード対応の「その他」メニューにまとめました。内蔵のライト・ダークテーマに説明を追加し、CPA 選択メニューの配色をサイドバーに合わせました。

## 修正

- 単一アーキテクチャのみを含む更新マニフェストを受け入れつつ、記載されたすべてのパッケージを検証します。Windows x64 のみの Preview チャンネルに対応し、安定版では引き続き Windows、macOS、Linux の x64・ARM64 パッケージを提供します。
