## 新增

- 可從側欄 CPA 選擇器連線至外部 CLIProxyAPI v8 服務，在獨立的 Remote 工作區管理用戶端 API 金鑰。支援 HTTP、HTTPS 與反向代理路徑前綴，條件式儲存可避免覆寫同時發生的修改。在內建 CPA 與 Remote CPA 之間切換後，需要完全結束並重新開啟 ECPA 才會生效。

## 改進

- ACP 帳號登入改用隔離的 CLI 設定，可新增及重新授權帳號而不取代其他已儲存帳號，並提供手動授權連結流程。改善 Windows CLI 啟動指令碼與路徑相容性；功能檢查失敗後仍可重試，並區分授權逾時、回應遭拒、未取得授權連結與網路故障。
- Stable 與 Preview 版本獨立比較。點擊桌面端標誌可切換版本管理頁顯示的版本參考，不會改變已安裝程式或背景更新通道；自動更新僅在目前安裝版本所屬系列內進行。
- 修正供應商模型選擇器的數量統計，保留上游清單未傳回的已設定模型並明確標示，避免模型遭無聲遺漏。
- 憑證卡片保留常用操作，將次要操作收納至支援鍵盤操作的「更多」選單；內建淺色與深色主題新增說明，CPA 選擇器配色與側欄保持一致。

## 修正

- 更新清單僅包含一種架構時也可正常辨識，同時繼續驗證所有列出的安裝套件，以支援僅提供 Windows x64 的 Preview 通道；正式版仍提供 Windows、macOS 與 Linux 的 x64 和 ARM64 安裝套件。
