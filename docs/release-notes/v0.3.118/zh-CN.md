## 新增

- 可从侧栏 CPA 选择器连接外部 CLIProxyAPI v8 服务，在独立的 Remote 工作区管理客户端 API 密钥。支持 HTTP、HTTPS 和反向代理路径前缀，条件保存可避免覆盖并发修改。在内置 CPA 与 Remote CPA 之间切换后，需要完全退出并重新打开 ECPA 才会生效。

## 改进

- ACP 账号登录改用隔离的 CLI 配置，可新增和重新授权账号而不替换其他已保存账号，并提供手动授权链接流程。改进 Windows CLI 启动脚本与路径兼容性；能力检查失败后仍可重试，并区分授权超时、响应被拒绝、未取得授权链接和网络故障。
- Stable 与 Preview 版本独立比较。点击桌面端标志可切换版本管理页显示的版本参考，不会改变已安装程序或后台更新通道；自动更新仅在当前安装版本所属系列内进行。
- 修正提供商模型选择器的数量统计，保留上游列表未返回的已配置模型并明确标注，避免模型被静默遗漏。
- 凭证卡片保留常用操作，将次要操作收纳到支持键盘操作的「更多」菜单；内置浅色和深色主题新增说明，CPA 选择器配色与侧栏保持一致。

## 修复

- 更新清单仅包含一种架构时也可正常识别，同时继续校验所有列出的安装包，以支持仅提供 Windows x64 的 Preview 通道；正式版仍提供 Windows、macOS 和 Linux 的 x64 与 ARM64 安装包。
