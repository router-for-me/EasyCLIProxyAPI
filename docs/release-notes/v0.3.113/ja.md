## 追加

- **ACP アカウントを管理できるようになりました**：保存済みアカウントにラベルが表示され、コンパクトなアカウントマネージャーからローカルで削除したり、個別にサインアウトしたり、再認可したりできます。1 つのクライアントを再ログインしても他のクライアントに影響しません。
- **削除したアカウントの履歴は保持されます**：保存済みアカウントを削除すると、データを破棄せずに関連付けだけを解除し、削除されたデータは残りのアカウントから分離されます。

## 改善

- **アカウント切り替えで中途半端な状態が残らなくなりました**：完了しなかった認可の試行はロールバックされ、アカウントの切り替えは完全に完了するか、以前の状態のまま留まるかのどちらかになります。

## 修正

- **アカウント切り替えで古いサインイン状態が残ることがありました**：切り替えはフェイルクローズになり、失敗または中止された認可が、それ以前に有効だった API の指定を変更することはなくなりました。
