## 新增

- **ACP 账号可以管理了**：已保存的账号会显示名称，可以在紧凑的账号管理器中本地删除、单独退出登录或重新授权，重新登录一个客户端不再影响其他客户端。
- **删除账号会保留历史数据**：删除已保存账号时只会解除关联而不会销毁数据，被移除的数据与剩余账号相互隔离。

## 改进

- **账号切换不再留下半完成状态**：未完成的授权尝试会被回滚，每次账号切换要么完整完成，要么保持切换前的状态。

## 修复

- **切换账号可能残留旧的登录状态**：账号切换现在改为失败即关闭（fail-closed），失败或取消的授权不会再改动此前生效的 API 指向。
