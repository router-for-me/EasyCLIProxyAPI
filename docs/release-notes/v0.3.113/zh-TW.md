## 新增

- **ACP 帳號可以管理了**：已儲存的帳號會顯示名稱，可以在精簡的帳號管理器中在本機刪除、單獨登出或重新授權，重新登入一個用戶端不再影響其他用戶端。
- **刪除帳號會保留歷史資料**：刪除已儲存的帳號時只會解除關聯而不會銷毀資料，被移除的資料與剩餘帳號相互隔離。

## 改進

- **帳號切換不再留下半完成狀態**：未完成的授權嘗試會被回滾，每次帳號切換要麼完整完成，要麼保持切換前的狀態。

## 修復

- **切換帳號可能殘留舊的登入狀態**：帳號切換現在改為失敗即關閉（fail-closed），失敗或取消的授權不會再改動此前生效的 API 指向。
