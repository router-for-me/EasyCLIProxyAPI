## 新增

- **新增俄语界面**：语言列表加入「Русский」，应用界面、托盘菜单、插件与模板帮助表格、MCP 与技能页面都会切换为俄语，无需重启即可生效。
- **俄语完整词典**：全部界面文案均为人工翻译，不会在俄语界面回退到英文；设置中保存的 `ru-RU`、`ru-BY` 等区域变体会自动归一化为俄语。
- **俄语更新说明**：更新清单可以携带 `ru.md` 正文，切换到俄语后版本管理中的更新说明同步切换。GitHub Release 页面仍保持英文在前、简体中文在后的排版。

## 优化

- **语言选项顺序**：语言下拉按简体中文、繁體中文、日本語、English、Русский 排列，原生名称始终以各自语言显示。
- **主题标签支持俄语**：自定义主题的 `name` 和 `description` 可以直接写 `ru` 译文，主题列表按当前界面语言显示。
- **文案一致性**：俄语中的 API Key、Base URL、Token、模型与渠道 ID 等标识保持拉丁字符，与日文界面的处理方式一致。

## 修复

- **俄语分支与主干的差异**：补全了自上次同步以来新增的代理参数、额度、用量统计、插件商店等 137 条文案，俄语界面不再出现英文短句。
- **发布说明测试**：更新说明的发布策略测试已按「英文 + 简体中文」的线上正文规则校准，并新增俄语清单用例。
