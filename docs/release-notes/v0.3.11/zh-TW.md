## 優化

- 繁體中文、日文和英文介面的側邊欄社群入口改為「加入 Discord 伺服器」，點擊後開啟 [Discord 社群](https://discord.gg/PxvX4D9kgs)；簡體中文介面仍使用原有的 QQ 入口。

## 修復

- 修復 macOS 上可能無法偵測到 WorkBuddy / WorkBuddy AI 的問題：依照應用程式套件 `Info.plist` 記錄的執行檔名稱定位程式；資訊缺失或無效時仍相容原有路徑。
- 修復連續儲存核心設定後，執行中的核心可能無法讀取後續變更的問題；使用統計開關、用戶端 API Key 等設定現在可在儲存後正常生效。
- 修復 macOS 更新後，新應用程式套件內的 OAuth 目錄已存在但為空時，舊憑據未從更新備份還原的問題。
