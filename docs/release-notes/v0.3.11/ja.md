## 改善

- 繁体字中国語・日本語・英語の画面では、サイドバーの連絡先を「Discord サーバーに参加」に変更しました。クリックすると [Discord サーバー](https://discord.gg/PxvX4D9kgs) が開きます。簡体字中国語の画面では、従来の QQ リンクを引き続き使用します。

## 修正

- macOS で WorkBuddy / WorkBuddy AI を検出できない場合がある問題を修正しました。アプリバンドルの `Info.plist` に記載された実行ファイル名を使用し、情報がない場合や無効な場合は従来のパスを使用します。
- コアの設定を繰り返し保存した後、実行中のコアが後続の変更を読み込まなくなる場合がある問題を修正しました。使用統計やクライアント API キーなどの設定が保存後に反映されます。
- macOS の更新後、新しいアプリバンドル内に空の OAuth ディレクトリがあると、更新バックアップから既存の認証情報が復元されない問題を修正しました。
