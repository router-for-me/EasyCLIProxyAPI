## 新增

- **WSL 运行环境自动探测与一键切换**：重构「智能体配置 → 配置管理」中的配置目录设置，新增「Windows 本地 / WSL 子系统」环境分段切换器；在 Windows 下自动扫描已安装的 WSL 发行版与 Linux 用户目录，点选即可自动推导并应用对应的 `\\wsl.localhost\<Distro>\home\<user>\...` 配置路径，无需手动拼写复杂的 UNC 路径，同时保留高级自定义路径折叠区。
- **路由编排全流程阶梯视图与网关策略重构**：重构路由编排页面为「左侧请求流阶梯 + 右侧粘性网关策略侧栏」双栏布局；支持沿纵向请求流轨展示各优先级层级的承接/待命/跳过状态与同层流量分担比例，支持拖拽凭据卡片至层间连线直接拆分新建层级、通过卡片快捷按钮或 `Alt + ↑/↓` 键盘快捷键调整层级、展示供应商与 OAuth 品牌图标，并将加权轮询权重芯片（`×1`）按需收敛至加权策略下显示。

## 修复

- **路由编排提供商密钥空前缀覆盖保留**：修复提供商分组配置了请求前缀而单个密钥显式将前缀清空（`prefix: ""`）时，路由编排卡片仍错误回退显示分组前缀的问题。
