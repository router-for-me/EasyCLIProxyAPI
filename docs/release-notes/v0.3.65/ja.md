## 新機能

- **WSL 実行環境の自動検出とワンクリック切り替え**：「エージェント設定 → 設定管理」の設定ディレクトリ設定を再設計し、「Windows ローカル / WSL サブシステム」の環境切り替えコントロールを追加しました。Windows 上でインストール済みの WSL ディストリビューションと Linux ユーザーディレクトリを自動スキャンし、選択するだけで対応する `\\wsl.localhost\<Distro>\home\<user>\...` 設定パスを自動適用できるため、複雑な UNC パスを手入力する必要がなくなりました（高度なカスタムパス指定用の折りたたみセクションも維持しています）。
- **フロー型ルーティング階層ラダーとゲートウェイポリシーサイドバーの再設計**：ルーティング構成ページを「左側のリクエストフロー階層ラダー + 右側の固定ゲートウェイポリシーサイドバー」の 2 カラム構成に再設計しました。縦方向のフローレールに沿って各優先度階層の稼働・待機・スキップ状態と同階層内のトラフィック配分比率を表示し、階層間のリンクへのドラッグ＆ドロップによる新規階層作成、クイック移動/分割ボタンと `Alt + ↑/↓` ショートカット、プロバイダーブランドアイコンの表示、および重み付きラウンドロビン選択時のみの重みチップ（`×1`）表示に対応しました。

## 不具合修正

- **ルーティング構成におけるキー単位の空プレフィックス上書きの保持**：プロバイダーグループにプレフィックスが設定されている状態で個別のキーが明示的にプレフィックスを空（`prefix: ""`）に上書きした際、ルーティングカードがグループのプレフィックスにフォールバックして表示される問題を修正しました。
