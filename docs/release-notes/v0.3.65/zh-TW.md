## 新增

- **WSL 執行環境自動偵測與一鍵切換**：重構「智慧代理設定 → 設定管理」中的設定目錄設定，新增「Windows 本機 / WSL 子系統」環境分段切換器；在 Windows 下自動掃描已安裝的 WSL 發行版與 Linux 使用者目錄，點選即可自動推導並套用對應的 `\\wsl.localhost\<Distro>\home\<user>\...` 設定路徑，無需手動拼寫複雜的 UNC 路徑，同時保留進階自訂路徑摺疊區。
- **路由編排全流程階梯檢視與閘道策略重構**：重構路由編排頁面為「左側請求流階梯 + 右側黏著閘道策略側欄」雙欄版面；支援沿縱向請求流軌顯示各優先級層級的承接/待命/略過狀態與同層流量分擔比例，支援拖放憑證卡片至層間連線直接拆分新建層級、透過卡片快捷按鈕或 `Alt + ↑/↓` 鍵盤快速鍵調整層級、顯示供應商與 OAuth 品牌圖示，並將加權輪詢權重晶片（`×1`）依需求收斂至加權策略下顯示。

## 修復

- **路由編排供應商金鑰空前綴覆寫保留**：修復供應商群組設定了請求前綴而單一金鑰明確將前綴清空（`prefix: ""`）時，路由編排卡片仍錯誤回退顯示群組前綴的問題。
