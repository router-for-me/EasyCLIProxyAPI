## 新增

- 關於軟體，如果您有任何問題或建議，請透過群組或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 提交，我們會盡快處理。
- 新增 Vertex AI 憑證匯入：在登入頁面選擇 Google 服務帳戶 JSON，可指定 GCP 區域；匯入成功後顯示專案、服務帳戶和憑證檔案資訊。
- Agent 設定管理支援手動選擇執行檔。自動偵測失敗時可指定路徑，並用於後續偵測與啟動。
- 使用記錄會為 `priority` 和 `fast` 請求顯示 Fast 標記。

## 優化

- 首頁改為更輕量的概覽版面，讓狀態與概覽資訊更加醒目。
- 使用記錄的顯示設定新增錯誤詳情換行選項；預設以單行顯示，也可展開查看完整內容，設定會保留。
- 改進 ZCode 設定更新與識別，相容既有網址寫法，並保留手動模型設定中的上下文視窗。
- 改進 Hermes 和 OpenClaw 設定相容性：識別 Hermes v12 的 provider 設定，遵循 OpenClaw 的自訂設定路徑，並保留現有模型中繼資料。
- 憑證用量明確標示為核心執行期間的統計，憑證啟用狀態與操作按鈕更加清晰；補齊部分介面文字翻譯。
- 內建 CLIProxyAPI 核心更新至 **8.0.22**。
- 優化 Claude Code 的映射。
