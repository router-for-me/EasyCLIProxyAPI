## 修正

- **macOS の更新ヘルパーが強制終了されなくなりました**: macOS でアプリを終了して更新を開始するとき、更新ヘルパーは独立したプロセスグループで動作するため、UI プロセスと一緒にシステムに終了させられることがなくなり、更新が最後まで実行されて正常に再起動します。
- **macOS でアプリのみを更新する場合にコアを保持**: アプリ本体のみの更新では、実行中のコアプロセスが一緒に終了しなくなり、更新後も既存のコアをそのまま使用します。通常終了時のコア停止動作は変わりません。
