## 修復

- **macOS 更新助手不再被誤殺**：在 macOS 上結束應用程式觸發更新時，更新助手會執行於獨立的行程群組中，不再隨介面行程一起被系統清除，更新能完整完成並正常重新啟動。
- **macOS 僅更新應用程式時保留核心**：只有應用程式本體需要更新時，正在執行的核心行程不再被一併結束，更新完成後繼續使用原核心；正常結束應用程式時的核心關閉行為維持不變。
