## Исправлено

- **Помощник обновления в macOS больше не завершается принудительно**: при выходе из приложения для запуска обновления помощник теперь работает в отдельной группе процессов, поэтому очистка завершающегося процесса интерфейса не останавливает его, и обновление проходит полностью с обычным перезапуском.
- **Обновление только приложения в macOS сохраняет работающее ядро**: если обновляется только само приложение, процесс ядра больше не завершается и продолжает работу после обновления. Обычное поведение при закрытии приложения не изменилось.
