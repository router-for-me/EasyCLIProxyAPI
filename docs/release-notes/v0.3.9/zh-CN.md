## 新增

- Linux 新增系统托盘：可从托盘打开主界面、查看内核状态、启动或停止内核、重启内核及退出应用；支持关闭窗口后留在托盘和静默启动。

## 优化

- 内置内核更新至 8.0.3。应用适配内核 v8 的配置结构和管理接口，包括 API 提供方、访问密钥、OAuth 模型别名、请求设置等数据的读取与保存。
- 改进窄屏窗口下的页面布局；为语言菜单、页面标签、弹窗和使用记录表格补充键盘操作、焦点管理与辅助功能标注。使用记录的列宽也可通过键盘调整。
- 未匹配到受支持语言时默认使用英文；将原先写死为中文的后端提示统一为英文，托盘菜单则跟随应用语言显示。

## 修复

- 修复 macOS 替换应用包后可能无法找到旧包内 OAuth 凭据目录的问题；从更新备份恢复凭据及其日志到持久化目录。自动更新后的配置加载失败时触发回滚，避免按默认设置确认升级成功。
- 修复内核升级时新版模板默认值可能覆盖原有设置的问题。从 v7 升级到 v8，以及更新部分已迁移的 v8 配置时，保留现有配置，避免 OAuth 凭据目录、端口和访问密钥等设置被重置。
- 修复未标记版本的 v8 配置在启动或修改访问密钥时，可能误将上游 API 凭据覆盖为访问密钥的问题。
- 内核启动日志改为追加写入，启动或重启内核时保留历史启动输出。
- 修复内核 v8 配置缺少可选节点时页面读取失败的问题；改进首次创建模型别名及保存失败后的回滚，避免空的配置父节点被误判为其他修改。
- 修复 Claude Code 通过 CPA 网关运行时可能触发服务端自动模式检查的问题。
- 修复 macOS 升级后旧版相对路径 OAuth 凭据目录可能导致已有凭据无法识别的问题。当相对路径目录中没有凭据，而持久化目录中有凭据时，自动恢复使用原有凭据。
- Linux 无可用系统托盘时保留主窗口，避免静默启动或最小化后无法重新打开应用。
- 将旧版相对路径 OAuth 凭据目录的自动恢复扩展至 Windows 和 Linux，并改进 macOS 的路径判断；恢复失败时保留现有配置和凭据。
- 修正各平台 OAuth 凭据目录和内核日志目录的路径解析，使打开目录和写入启动日志的位置与内核实际使用的路径一致。
- 修复未标记版本但使用 v8 结构的内核配置在保存 TLS、日志及 OAuth 凭据目录等设置时可能写错位置的问题；同时支持更新行内 YAML 映射。
