## 追加

- **モデルのヘルスチェックから直接モデルを切り替え**：ヘルスチェックダイアログの各モデル行に有効／無効のスイッチを追加しました。編集ダイアログを開いて除外リストを変更する必要はありません。スイッチの状態はその接続が持つ既存の `excluded-models` 設定に書き戻され、そのモデル自身の完全一致ルールのみを追加・削除します。プロバイダー全体のワイルドカード除外や手動で追加した除外ルールはそのまま残ります。
- **無効化したモデルが一目で分かる**：無効化したモデル行は淡い背景色になり、モデル名と結果ラベルも同時に淡くなるため、現在利用できるモデルの範囲がすぐに分かります。

## 改善

- **狭いウィンドウでのヘルスチェック一覧**：狭い幅ではモデル行が縦並びになり、名前、スイッチ、結果、操作ボタンの順に配置されるため、結果ラベルが潰れることがなくなりました。
- **説明文の折り返し**：説明文は句読点でのみ折り返すようになり、「正常」が「正／常」のように単語の途中で分割されなくなりました。

## 修正

- **保存に失敗したときのスイッチの復帰**：モデルのスイッチを書き込めなかった場合、スイッチは操作前の状態に戻りエラーを表示します。保存された設定と異なる状態が表示されることはなくなりました。
