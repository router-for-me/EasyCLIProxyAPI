## Desktop and CPA updates

- Manage the selected CPA instance with a visual configuration editor or edit its source directly. App Preferences and Diagnostics have updated layouts.
- Routing ladders show credential remarks and can temporarily hide disabled credentials. Provider and credential model exclusions are synchronized.
- ACP supports pooling and failover across signed-in accounts. Local access recovers after switching back from a remote instance, and accounts can sign in again individually.
- ZCode gains a model catalog, sub-agent settings and local usage scanning. The bundled Codex model catalog adds 6.2, and usage records avoid inflated Codex token counts.
- Automatic app upgrades now work from PR, preview and local test builds. The bundled CPA core is updated to 8.1.3.
