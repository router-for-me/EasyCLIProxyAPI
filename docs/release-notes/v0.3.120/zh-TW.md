## 桌面版與 CPA 更新

- 管理目前選取的 CPA 執行個體時，可以使用視覺化設定編輯器，也可以直接編輯設定原始碼。應用程式偏好設定和診斷頁面調整了版面。
- 路由階梯會顯示憑證備註，並可暫時隱藏已停用的憑證；供應商與憑證的模型排除設定會保持同步。
- ACP 支援多帳號並行集區與容錯移轉。從遠端執行個體切回時可恢復本機存取，各帳號也可個別重新登入。
- ZCode 新增模型目錄、子代理設定和本機用量掃描。內建 Codex 模型目錄加入 6.2，並修正 Codex Token 用量偏高的問題。
- PR、預覽和本機測試組建現在也支援應用程式內自動升級。內建 CPA 核心更新至 8.1.3。
