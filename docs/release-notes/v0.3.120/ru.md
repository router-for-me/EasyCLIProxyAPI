## Обновления приложения и CPA

- Настройки выбранного экземпляра CPA теперь можно менять в визуальном редакторе или напрямую в исходном файле. Обновлено оформление настроек приложения и страницы диагностики.
- В списке уровней маршрутизации видны примечания к учётным данным; отключённые записи можно временно скрыть. Исключения моделей у провайдеров и учётных данных синхронизируются.
- ACP поддерживает пул аккаунтов и переключение при сбое. После возврата с удалённого экземпляра доступ к локальному восстанавливается; повторный вход доступен для каждого аккаунта.
- В ZCode добавлены каталог моделей, настройки подагентов и чтение локальной статистики. Модель 6.2 добавлена во встроенный каталог Codex; исправлен завышенный подсчёт токенов Codex.
- Автообновление приложения теперь работает также из сборок PR, предварительных и локальных тестовых сборок. Встроенное ядро CPA обновлено до 8.1.3.
