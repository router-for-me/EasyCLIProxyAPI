## デスクトップと CPA の更新

- 選択中の CPA インスタンスをビジュアルエディターで設定するか、設定ファイルを直接編集できます。アプリ設定と診断画面のレイアウトも更新しました。
- ルーティングの階層表示に認証情報のメモが表示され、無効な認証情報を一時的に非表示にできます。プロバイダーと認証情報のモデル除外設定を同期します。
- ACP が複数アカウントのプールとフェイルオーバーに対応しました。リモートから切り替えた後にローカルアクセスが復旧し、アカウントごとに再ログインできます。
- ZCode にモデルカタログ、サブエージェント設定、ローカル使用量の読み取りを追加しました。同梱の Codex カタログに 6.2 を追加し、トークン数の過大計上を修正しました。
- PR、プレビュー、ローカルテストの各ビルドからもアプリ内で自動更新できるようになりました。同梱の CPA コアを 8.1.3 に更新しました。
