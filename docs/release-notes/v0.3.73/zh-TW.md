## 修復

- **套用方案按鈕不再無聲變灰**：路由編排頁面中，當方案有驗證問題時，「套用方案」按鈕旁會直接顯示具體原因（例如工作階段有效期格式不正確），不再只是變灰讓人無從下手。
- **工作階段有效期格式提示**：填寫工作階段有效期時，若漏掉時間單位（例如只寫 `3`），輸入框會立即標紅並提示「工作階段有效期必須帶時間單位，例如 1h、30m 或 1h30m。」。該欄位仍只接受帶單位的時長，`1h`、`30m`、`1h30m` 均可正常套用。

## 優化

- **閘道策略欄位說明**：請求重試次數、重試憑證數、最大重試等待、暫時錯誤冷卻與「停用冷卻」開關下方各增加一行說明，不再只有欄位名稱和數字框。

## 新增

- **MCP 服務與 Agent 技能集中管理**：新增「MCP 與技能」頁面，集中列出應用程式可見的 MCP 服務與 Agent 技能，並提供各自的詳細面板。
  - MCP 服務顯示傳輸方式（stdio、HTTP 或 SSE）、指令或 URL、啟動參數與環境變數，以及啟用狀態；支援新增、編輯、刪除、啟用與停用，並可將整份清單以 JSON 匯入匯出。
  - 技能依來源（OpenClaw、專案、技能工坊或自訂目錄）分類，顯示描述、路徑與檔案數量，可個別啟用或停用，並在閱讀面板中檢視技能內容。
  - 兩個分頁頂端都有篩選列，可依傳輸方式或來源縮小清單；頁面在 640px 的最小視窗下仍可正常使用。
- **內建反向代理**：新增可選的反向代理服務，為本機核心服務提供 TLS 終止，可在設定頁設定憑證與監聽連接埠。
