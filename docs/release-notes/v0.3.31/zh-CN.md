## v0.3.31

- 关于软件，如果您有任何问题或建议，请通过 [联系我们](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 提交，我们会尽快处理。

## 优化

- 优化 Claude Code 模型显示，按“角色 · 模型名称”展示，为启用 1M 的模型添加 `[1m]` 标记，并明确自动压缩窗口大小。
- Claude Desktop 模型映射新增“使用模型别名”筛选开关，方便切换原始模型与别名列表。

## 修复

- 修复手动指定 OpenCode 桌面程序路径后，“一键接入”仍提示 `OpenCode is not installed` 的问题（[#389](https://github.com/router-for-me/EasyCLIProxyAPI/issues/389)）。智能体应用、更新和启用配置时会使用已设置的程序路径。
- 修复 Pi 插件安装、更新和卸载时未使用手动指定 CLI 路径的问题。
- 修复 Claude Code 和 Claude Desktop 中，原始模型配置了别名后被错误隐藏的问题。关闭“使用模型别名”时保留全部可用原始模型，恢复搜索和选择；此修复适用于所有模型。
- 修复 Claude Code 启用 1M 时覆盖自定义自动压缩窗口的问题。200K / 1M 默认值仍随开关调整，其他自定义值会保留。
- 完善 Claude Code 上下文与自动压缩窗口的配置写入，使相关设置保持一致。
- 修复 Fable 未单独配置、回退使用 Sonnet 时，没有同步继承 Sonnet 1M 设置的问题。

## v0.3.30

## 新增

- 同时提供命令行和桌面版的智能体（Codex、OpenCode、DeepSeek Harness）现在可以分别指定命令行程序路径和桌面程序路径。自动检测失败时，启动和重新检测会使用对应路径。
- 模型别名允许被多个来源共用；相同别名可以分别编辑和删除，保存时不会互相覆盖。

## 优化

- 重新设计侧边栏：导航更紧凑，当前页面更明确；新手模式和联系方式改为普通入口，语言与主题切换合并到同一工具栏。
- 调整模型别名列表布局，思考等级和 Fast 标记不再挤动编辑和删除按钮。
- 智能体配置页会保留已选择的模型。刷新后模型暂时不在列表中时，不会自动换成第一项，并提示当前选择已不可用。
- 应用更新进度只显示当前阶段，避免进度说明重复跳动。
- 将“恢复历史会话”改为“同步历史会话”，并说明 ChatGPT 会按 API 隔离会话；需要旧会话时，可在会话管理中同步。

## 修复

- API 接入页会记住上次选择的服务商分类。
- 保存模型别名时保留无关的配置改动。
