## 改善

- Claude Code のモデル表示を「役割 · モデル名」に統一しました。1M を有効にしたモデルには `[1m]` を表示し、自動圧縮ウィンドウのサイズも明示します。
- Claude Desktop のモデルマッピングに、元のモデルとエイリアスの一覧を切り替えるフィルターを追加しました。

## 修正

- OpenCode デスクトップアプリのパスを手動で指定しても、ワンクリック設定で `OpenCode is not installed` と表示される問題を修正しました（[#389](https://github.com/router-for-me/EasyCLIProxyAPI/issues/389)）。エージェント設定の適用・更新・有効化で、指定した実行ファイルのパスを使用します。
- Pi プラグインのインストール・更新・アンインストールで、手動指定した CLI パスが無視される問題を修正しました。
- Claude Code と Claude Desktop で、エイリアスがある元のモデルが誤って非表示になる問題を修正しました。エイリアスの使用をオフにすると、利用可能なすべての元モデルを検索・選択できます。すべてのモデルが対象です。
- Claude Code で 1M を有効にした際、カスタムの自動圧縮ウィンドウが上書きされる問題を修正しました。既定の 200K / 1M は切り替えに連動し、それ以外のカスタム値は保持されます。
- Claude Code のコンテキストと自動圧縮ウィンドウの設定書き込みを補完し、関連設定の整合性を改善しました。
- Fable を個別に設定せず Sonnet にフォールバックする場合、Sonnet の 1M 設定が継承されない問題を修正しました。

## 追加

- ソフトウェアについてご質問やご提案がある場合は、[Discord](https://discord.gg/PxvX4D9kgs) または [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) からお知らせください。できるだけ早く対応します。
- コマンドライン版とデスクトップ版の両方がある Agent（Codex、OpenCode、DeepSeek Harness）で、CLI プログラムのパスとデスクトップアプリのパスを別々に指定できるようになりました。自動検出に失敗した場合、起動と再検出には対応するパスを使用します。
- モデルエイリアスを複数の参照元で共有できるようになりました。同じエイリアスも個別に編集・削除でき、保存時に互いに上書きしません。

## 改善

- サイドバーを再設計しました。ナビゲーションをコンパクトにし、現在のページを分かりやすくしました。初心者モードと連絡先は通常の項目になり、言語とテーマの切り替えは同じツールバーにまとめています。
- モデルエイリアス一覧のレイアウトを調整し、思考レベルと Fast バッジが編集・削除ボタンの位置をずらさないようにしました。
- Agent 設定ページで選択したモデルを保持するようにしました。更新後に一覧から一時的に消えても先頭のモデルへ置き換えず、現在の選択が利用できないことを表示します。
- アプリ更新の進行状況は現在の段階だけを表示し、説明が重複したり動いたりしないようにしました。
- 表示を「過去のセッションを同期」に変更し、ChatGPT が API ごとに会話を分離することを説明しました。以前の会話はセッション管理から同期できます。

## 修正

- API 接続ページで、最後に選択したプロバイダー分類を記憶するようにしました。
- モデルエイリアスの保存時に、関係のない設定変更を保持するようにしました。
