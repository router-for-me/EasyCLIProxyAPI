## 改善

- **リリースパッケージの信頼性**: macOS の DMG 作成が失敗した場合は再試行し、そのイメージ自身がマウントしたボリュームだけをアンマウントします。Intel 版 macOS は Apple Silicon のビルドマシンでクロスコンパイルし、Linux は mold でリンクします。リリース資産のダウンロードでは、まだアップロードが完了していない資産を再試行し、ビルドを失敗させません。

## 修正

- **プラグインストアのスタイル**: プラグインのロゴ以降のルールがコンポーネントレイヤーから外れなくなり、ストアの結果バーの余白が元に戻り、スタイルシートの構文エラーも解消されました。
