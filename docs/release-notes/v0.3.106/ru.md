## Улучшения

- **Надёжность сборки релиза**: При сбое создания DMG в macOS образ создаётся повторно, и размонтируется только его собственный том; сборка Intel-версии macOS выполняется кросс-компиляцией на машине Apple Silicon; в Linux используется компоновщик mold; при скачивании файлов релиза ещё не загруженный файл запрашивается повторно, а не приводит к сбою сборки.

## Исправления

- **Стили магазина плагинов**: Правила после блока с логотипом плагина больше не выходят из слоя компонентов, поэтому полоса результатов магазина вновь получает свой отступ, а таблица стилей разбирается без синтаксической ошибки.
