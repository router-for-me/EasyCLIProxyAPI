## 优化

- 启动时自动升级内置内核：应用启动时若检测到本地已安装的内核版本低于当前安装包内置版本，会自动升级至内置内核并恢复运行状态（此前仅在缺失内核时自动安装）。
- 界面文案调整：将导航栏及 API 接入中的“高级设置”统一更名为“高级功能”。

## 修复

- 修复软件更新可能受缓存影响或沿用过期任务状态的问题：为更新检查与清单请求增加防缓存机制，并在开始下载前重新刷新最新版本信息。
