## 優化

- 啟動時自動升級內建核心：應用程式啟動時若偵測到本機已安裝的核心版本低於目前安裝包內建版本，會自動升級至內建核心並恢復執行狀態（此前僅在缺少核心時自動安裝）。
- 介面文案調整：將導覽列及 API 接入中的「進階設定」統一更名為「進階功能」。

## 修正

- 修復軟體更新可能受快取影響或沿用過期工作狀態的問題：為更新檢查與清單請求增加防快取機制，並在開始下載前重新整理最新版本資訊。
