## 改善

- エージェント管理ワークベンチのレイアウトを整理しました。デスクトップではクライアント一覧と設定パネルを見やすい比率に保ち、タブを設定領域の上部に固定して、長い内容を領域内で個別にスクロールできます。狭いウィンドウでは従来どおりページ全体を自然にスクロールできます。
- クライアント一覧のスクロールとテキスト配置を改善し、長い名前、バージョン、状態情報をさまざまなウィンドウサイズで読みやすくしました。
- Token トレンドグラフの横軸がウィンドウ幅に合わせて滑らかに変化するよう改善しました。ウィンドウを広げたり狭めたりすると目盛りの密度が段階的に調整され、ラベルが疎なままになったり急に密集したりする状況を抑えます。
- 同梱コアを 7.3.12 に更新しました。

## 修正

- 対応クライアントの有効な設定ファイルが存在していても、実行ファイルを検出できない場合に CPA へ接続できなかった問題を修正しました。設定ファイルがあればモデルの選択と CPA 設定の編集が可能になり、WorkBuddy、Pi を含むすべての対応クライアントで同じ動作になります。クライアントを検出するまでは起動と再起動のみ無効のままです。
