## 優化

- 重新整理智慧代理管理工作台版面：用戶端清單與設定區域在桌面視窗中保持更清楚的比例，分頁固定在設定區頂部，較長內容可在區域內獨立捲動；窄視窗下則繼續使用自然頁面捲動。
- 優化用戶端清單的捲動與文字版面，較長的名稱、版本與狀態資訊在不同視窗尺寸下更容易閱讀。
- Token 趨勢圖的橫軸現在會依視窗寬度動態調整刻度密度，拉寬或縮窄視窗時變化更均勻，減少標籤過疏或突然變密的情況。
- 內建核心更新至 7.3.12。

## 修正

- 修正用戶端已有設定檔、但未偵測到可執行程式時無法接入 CPA 的問題。現在只要設定檔存在且有效，就可以選擇模型並修改 CPA 設定；此規則統一套用到 WorkBuddy、Pi 等所有支援的用戶端。未偵測到用戶端時，啟動與重新啟動功能仍會保持停用。
