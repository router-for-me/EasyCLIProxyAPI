## 优化

- 重新整理智能体管理工作台布局：客户端列表与配置区域在桌面窗口中保持更清晰的比例，页签固定在配置区顶部，长内容可在区域内独立滚动；窄窗口下则继续使用自然页面滚动。
- 优化客户端列表的滚动和文字布局，长名称、版本与状态信息在不同窗口尺寸下更易阅读。
- Token 趋势图横坐标现在会跟随窗口宽度动态调整刻度密度，拉伸或收窄窗口时过渡更均匀，减少标签过疏或突然变密的情况。
- 内置内核更新至 7.3.12。

## 修复

- 修复客户端已存在配置文件、但未检测到可执行程序时无法接入 CPA 的问题。现在只要配置文件存在且有效，就可以选择模型并修改 CPA 配置；该规则统一适用于 WorkBuddy、Pi 等所有受支持的客户端。未检测到客户端时，启动和重启功能仍会保持禁用。
