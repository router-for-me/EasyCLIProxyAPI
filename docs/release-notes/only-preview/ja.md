## 修正

- **プレビュー版で常に古いビルドへの更新が表示される**：プレビュータグのタイムスタンプを解析する整数型が小さすぎたため、`202611041750` のような値が必ずオーバーフローし、「最新のプレビュービルドを探す」処理が黙って失敗していました。64 ビット整数で解析するよう変更し、最新のプレビュービルドを正しく指すようになりました。
- **リバースプロキシの無効状態が再起動で失われる**：リバースプロキシを無効にしてアプリを再起動すると、スイッチが有効に戻っていました。状態が正しく保存・復元されるようになりました。
- **リバースプロキシの再起動フラグが上書きされる**：リバースプロキシ設定の変更後、再起動が必要というマーカーが後続の書き込みで消えなくなり、コア設定のパスも正しく解決されます。

## 改善

- **プレビュービルドのタグを一意に**：プレビュービルドごとにタイムスタンプ付きの一意なタグを使用し、古いプレビューリリースを自動的に整理するため、複数のビルドが互いを上書きしません。
- **ダウンロードチャネルの説明を明確に**：バージョン管理ページでプレビュー版と正式版のダウンロード先を区別し、各チャネルの内容を説明するようにしました。
- **MCP と Skill ページの状態表示を改善**：読み込みに失敗したときに空白のページではなく、インラインのエラー表示と空状態を示すようになり、一覧の余白とレイアウトも調整しました。
- **MCP エントリを OpenClaw 設定へ同期**：MCP サーバーとエージェントスキルのエントリを、手作業でコピーせずに OpenClaw 設定へ書き込めるようになりました。
