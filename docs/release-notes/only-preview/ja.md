## 不具合修正

- **「構成を適用」ボタンが理由もなく無効化されなくなりました**：ルーティング構成ページで、構成に検証エラーがある場合は「構成を適用」ボタンの横に具体的な理由（セッション有効期間の形式が正しくないなど）が表示されます。
- **セッション有効期間の形式ガイド**：単位を付けずにセッション有効期間（例：`3`）を入力すると、入力欄が強調され「セッション有効期間には単位が必要です（例: 1h、30m、1h30m）。」と表示されます。この項目は引き続き単位付きの期間のみを受け付け、`1h`、`30m`、`1h30m` はいずれも適用できます。

## 改善

- **ゲートウェイポリシーの項目説明**：リクエスト再試行回数、再試行する認証情報数、最大再試行待機、一時エラーのクールダウン、クールダウン無効化の各項目に見出し1行の説明を追加しました。

## 追加

- **組み込みリバースプロキシ**：ローカルコアサービスに TLS 終端を提供する任意のリバースプロキシサービスを追加しました。設定ページで証明書と待受ポートを設定できます。
