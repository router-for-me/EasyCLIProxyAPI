## 修复

- **预览版总是提示更新到旧构建**：解析预览标签时间戳时使用的整数类型太小，`202611041750` 这样的时间戳必然溢出，导致「查找最新预览版本」一直静默失败。现在改用 64 位整数解析，更新能正确指向最新一次预览构建。
- **反向代理关闭状态重启后失效**：关闭反向代理后重启应用，开关会重新变成启用，现在会正确保存并恢复。
- **反向代理重启标记被冲掉**：修改反向代理配置后，重启提示标记不再被后续写入清除，内核配置路径也能正确解析。

## 优化

- **预览构建标签唯一化**：每次预览构建使用带时间戳的唯一标签，并自动清理更早的预览 Release，多个构建不会互相覆盖。
- **下载渠道说明更清晰**：版本管理页明确区分预览版与正式版的下载目标，并为每个渠道补充说明文字。
- **MCP 与 Skill 页面状态更完整**：加载失败时显示行内错误条和空状态，不再是一片空白；列表间距与排版也做了打磨。
- **MCP 条目可同步到 OpenClaw 配置**：MCP 服务器与 Agent Skill 条目现在可以同步写入 OpenClaw 配置，不用再手工复制。
