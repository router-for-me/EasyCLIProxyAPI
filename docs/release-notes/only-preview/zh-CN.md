## 修复

- **应用方案按钮不再无声置灰**：路由编排页面中，当方案存在校验问题时，「应用方案」按钮会在旁边直接显示具体原因（例如会话有效期格式不正确），不再只是变灰让人无从下手。
- **会话有效期格式提示**：填写会话有效期时，如果漏掉时间单位（例如只写 `3`），输入框会立即标红并提示「会话有效期必须带时间单位，例如 1h、30m 或 1h30m。」。该字段仍只接受带单位的时长，`1h`、`30m`、`1h30m` 均可正常应用。

## 优化

- **网关策略字段说明**：请求重试次数、重试凭证数、最大重试等待、瞬时错误冷却与「禁用冷却」开关下方各增加一行说明，不再只有字段名和数字框。

## 新增

- **MCP 服务与 Agent 技能集中管理**：新增「MCP 与技能」页面，集中列出应用可见的 MCP 服务与 Agent 技能，并提供各自的详情面板。
  - MCP 服务显示传输方式（stdio、HTTP 或 SSE）、命令或 URL、启动参数与环境变量，以及启用状态；支持新增、编辑、删除、启用与停用，并可将整份列表以 JSON 导入导出。
  - 技能按来源（OpenClaw、项目、技能工坊或自定义目录）归类，显示描述、路径与文件数量，可单独启用或停用，并在阅读面板中查看技能内容。
  - 两个标签页顶部都有筛选条，可按传输方式或来源缩小列表；页面在 640px 的最小窗口下仍可正常使用。
- **内置反向代理**：新增可选的反向代理服务，为本地核心服务提供 TLS 终止，可在设置页配置证书与监听端口。
