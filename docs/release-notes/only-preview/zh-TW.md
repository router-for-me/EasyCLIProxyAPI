## 修復

- **預覽版總是提示更新到舊建置**：解析預覽標籤時間戳時使用的整數型別太小，`202611041750` 這樣的時間戳必然溢位，導致「尋找最新預覽版本」一直靜默失敗。現在改用 64 位元整數解析，更新能正確指向最新一次預覽建置。
- **反向代理關閉狀態重啟後失效**：關閉反向代理後重啟應用程式，開關會重新變成啟用，現在會正確儲存並還原。
- **反向代理重啟標記被覆蓋**：修改反向代理設定後，重啟提示標記不再被後續寫入清除，核心設定路徑也能正確解析。

## 優化

- **預覽建置標籤唯一化**：每次預覽建置使用帶時間戳的唯一標籤，並自動清理較早的預覽 Release，多個建置不會互相覆蓋。
- **下載頻道說明更清晰**：版本管理頁明確區分預覽版與正式版的下載目標，並為每個頻道補充說明文字。
- **MCP 與 Skill 頁面狀態更完整**：載入失敗時顯示行內錯誤條和空狀態，不再是一片空白；列表間距與排版也做了打磨。
- **MCP 條目可同步到 OpenClaw 設定**：MCP 伺服器與 Agent Skill 條目現在可以同步寫入 OpenClaw 設定，不用再手工複製。
