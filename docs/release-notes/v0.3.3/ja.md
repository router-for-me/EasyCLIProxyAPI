## 新機能

- API 接続と簡易モードに、API ごとのプロキシ URL 設定を追加しました。HTTP、HTTPS、SOCKS5。
- 使用記録の料金統計で、Models.dev または LiteLLM からモデル価格を取得できるようになりました。更新前に一致したモデルを確認し、価格を編集して保存対象を選択できます。既存の手動設定価格は初期状態では選択されません。

## 改善

- 内蔵のモデル価格を更新し、GPT-6 Sol、GPT-6 Luna、Grok 4.7 などの価格を追加しました。
- キャッシュ読み取り、キャッシュ作成、長いコンテキストのコスト見積もりを調整しました。価格が設定されていないキャッシュ料金は自動推定しなくなりました。
- 内蔵コアを 7.3.17 に更新しました。
