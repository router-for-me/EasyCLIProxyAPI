## 新機能

- エージェント管理の Codex モデル設定に、公式の GPT-6 Sol と GPT-6 Luna のテンプレートを追加しました。
- 詳細設定に「機密語の難読化」ページを追加しました。Antigravity と Devin のシステムプロンプトに使用する語句を個別に編集でき、項目の追加・変更・削除や複数行の貼り付けに対応します。

## 改善

- Windows のビルドスクリプトを改善しました。作業フォルダーの移動後に古い Tauri ビルドキャッシュを検出して更新します。`-SkipCopy` を指定すると、ポータブル版アプリを実行したままコピーを省略してビルドできます。
- クォータのリセットまでの残り時間を、日・時間・分で切り上げずに表示するよう調整しました。

## 修正

- 同じリクエスト ID の使用イベントが複数ある場合、古い使用記録が一覧の先頭に残る問題を修正しました（#298）。
